Q-MAT-09-POL-P05-HOTS-01 PDF Page 5 (Book 2.26)
HARD Integer Polynomial Divisibility & Number-Theoretic Primes
1. Find the number of positive integers x for which f(x) = x^3 - 8x^2 + 20x - 13 is a prime number.
(A) 3
(B) 2
(C) 1
(D) 0
Official Answer Key: A Hardness: C=C3, R=R2, M=M3, A=A2
Independent derivation: f(1) = 1 - 8 + 20 - 13 = 0, so (x-1) is a factor. Division gives f(x) = (x-1)(x^2 - 7x + 13). For f(x) to be prime, either x - 1 = 1 (x=2 => f(2)=3 prime), x - 1 = -1 (x=0 not positive), or x^2 - 7x + 13 = 1 => (x-3)(x-4)=0 => x=3 (f(3)=2 prime), x=4 (f(4)=3 prime). Admissible positive integers are x in {2, 3, 4}, count = 3.

MEDIUM Factor Theorem & Parameter Solving
14. The polynomial p(x) = 2x^4 - x^3 - 7x^2 + ax + b is divisible by x^2 - 2x - 3 for certain values of a and b. The value of (a + b) is:
(A) -34
(B) -15
(C) -19
(D) 34
Official Answer Key: A Hardness: C=C2, R=R1, M=M2, A=A2
Independent derivation: Divisor x^2 - 2x - 3 = (x - 3)(x + 1). By factor theorem, p(3) = 0 and p(-1) = 0. p(-1) = 2(1) - (-1) - 7(1) - a + b = -4 - a + b = 0 => b - a = 4. p(3) = 2(81) - 27 - 7(9) + 3a + b = 72 + 3a + b = 0 => 3a + b = -72. Subtracting gives 4a = -76 => a = -19, b = -15. Thus a + b = -34.
