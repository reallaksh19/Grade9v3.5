Linear equations in one unknown: Construction

An equation constrains an unknown

Subject: MathematicsTopic: Linear equationsConcept: An equation constrains an unknownConcept difficulty: Medium concept

You need

  • Can evaluate an arithmetic expression containing a given number.
  • Decide whether a given value satisfies an equation by substituting it.

The key step

Read a*x + b = c as a statement that is true for some values of the unknown and false for others, rather than as an instruction to work out a left-hand side.

Test a value by putting it into the equation and comparing the two sides, before changing the equation at all.

  1. Declare the domain the unknown ranges over.
    Why valid: A solution set has no meaning until the admissible values are fixed.
    Result: x ranges over the rationals.
  2. Substitute a candidate value and evaluate both sides separately.
    Why valid: Membership of the solution set is decided by substitution, which is the definition of a solution.
    Result: For x = 2: 3(2) + 2 = 8, and the right side is 9, so 8 = 9 is false.
  3. Try a second value that fails, and say why it fails.
    Why valid: A constraint is only understood once a non-solution has been seen.
    Result: Evidence that the equation selects values rather than computing one.

Worked example

Solve 3x + 2 = 9 over the rationals. Give the exact solution and verify it.

  1. Subtract 2 from both sides; the operation is reversible, giving 3x = 7.
  2. Divide both sides by 3, which is non-zero and therefore reversible, giving x = 7/3.
  3. Substitute back: 3 times 7/3 is 7, and 7 plus 2 is 9, exactly as required.

x = 7/3.

A tempting wrong path

  • The equals sign means work out the left side and write the answer on the right.

Diagnose

  • In 3x + 2 = 9, what would you 'work out' before you know x?

Repair

  • Read the statement aloud as a claim about the unknown, then test one value by substitution before manipulating anything.

Check it independently

  • Substitute the candidate: both sides must give the same number exactly.

Exit task

Does x = 2 satisfy 3x + 2 = 9? Show how you decided.
