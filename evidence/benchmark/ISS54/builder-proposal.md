## 1. Executive Summary & Problem Diagnosis

Inspection of the rendered learner pages (`core1a.html` and `core2.html`) generated by `Shared/tools/render_core.py` reveals that while static multi-stage SVG illustrations (`rational-domain-puncture.svg`, `polynomial-area-tiles.svg`, `parabola-zeros-intercepts.svg`) accurately depict the geometric figures and punctured points, **learners consistently struggle with the distinction between algebraic formula simplification and function domain identity**.

In particular, **Question 6** represents the conceptual crux of the D2 benchmark:
- **Task**: Compare the rational expression $r(x) = \frac{x^2-1}{x-1}$ with the linear polynomial $q(x) = x+1$. State the domain of $r$, simplify it where valid, and decide whether $r$ and $q$ are the same function on all real numbers, addressing $x=1$ explicitly.
- **Cognitive Failure Mode**: Learners mechanically perform algebraic cancellation $\frac{(x-1)(x+1)}{x-1} = x+1$ and jump to the false conclusion that $r$ and $q$ are identical functions across all real numbers $\mathbb{R}$. They overlook that algebraic cancellation is conditioned on $x-1 \neq 0$ and that division by zero at $x=1$ permanently excludes $1$ from the domain of $r$.
- **Limitation of Current Renderer**: The static template provides stepped disclosure of the SVG graphic, but lacks an interactive probe where learners can dynamically drag an evaluation cursor toward $x = 1.000$ to witness the sudden transition from numerical equality ($0.999 \to 1.999$) to an evaluation failure (`0/0 — UNDEFINED`), directly confronting the misconception that "cancelling makes the hole disappear".

## 2. Proposed Interactive Feature: `<rational-domain-inspector>`

We propose introducing a lightweight, reusable web component / template module into the core template engine: `<rational-domain-inspector>`.

### 2.1 Component Architecture & State Schema

```typescript
interface RationalDomainInspectorState {
  functionDef: {
    numeratorFormula: string;    // e.g. "x^2 - 1"
    denominatorFormula: string;  // e.g. "x - 1"
    simplifiedFormula: string;   // e.g. "x + 1"
    excludedPoints: number[];    // e.g. [1.0]
  };
  cursor: {
    xValue: number;              // Current probed x value
    stepSize: number;            // 0.1, 0.01, 0.001
  };
  evaluation: {
    numeratorVal: number;
    denominatorVal: number;
    originalVal: number | 'UNDEFINED';
    simplifiedVal: number;
    status: 'EQUAL' | 'SINGULARITY' | 'VALID_EVALUATION';
  };
  displayOptions: {
    showTable: boolean;
    showGraphCrosshair: boolean;
    showLimitDelta: boolean;
  };
}
```

### 2.2 Pedagogical Interaction Design for Q6

1. **Continuous Probe Slider**:
   - The learner drags an interactive slider across $x \in [-2, 3]$.
   - At $x = 0.9$, $r(x) = 1.9$ and $q(x) = 1.9$ (Status: **AGREE**).
   - At $x = 0.99$, $r(x) = 1.99$ and $q(x) = 1.99$ (Status: **AGREE**).
   - At exactly $x = 1.000$, the denominator evaluates to $0$. The $r(x)$ card immediately transforms into a high-visibility warning state:
     $$\text{Denominator } (x - 1) = 0 \implies r(1) = \frac{0}{0} \quad [\text{UNDEFINED}]$$
     while $q(x)$ cleanly outputs $q(1) = 2.0$.
2. **Synchronized Graphical Hole Piercing**:
   - On the interactive canvas, dragging the slider moves a tracing point along $y = x+1$.
   - When the cursor reaches $x = 1$, the solid point on $r(x)$ hollows out into an empty ring with a pulsing red halo and tooltip: *"Domain Puncture: Point does not exist on $r(x)$"*.
3. **Misconception Challenge Mode**:
   - The component poses an active question: *"Does simplifying $(x-1)/(x-1) = 1$ redefine the domain of $r$?"*
   - Learners select **YES** or **NO**; selecting YES triggers an immediate counter-evaluation proving that substituting $x=1$ into the original formula yields illegal division by zero.

## 3. Minimal Reusability & Schema Compatibility

- **Subject Reusability**:
  - In **Mathematics**: Directly reusable for rational functions, vertical asymptotes, removable discontinuities, calculus limits, and parameter threshold points.
  - In **Physics**: Applicable to velocity-time domain singularities (e.g., impulsive collisions, division by zero time intervals $\Delta t \to 0$).
- **Zero-Dependency Implementation**:
  - Built as a pure vanilla Custom Element (`class RationalDomainInspector extends HTMLElement`) using standard browser DOM and SVG primitives.
  - Requires no external libraries, polyfills, or build steps; functions completely offline over `file://` protocol.
- **Blueprint Schema Integration**:
  - Declared in `Shared/web/interactive-page-blueprints.v1.json` as an optional rich interaction component under `CORE1A` and `CORE2` blueprints.
  - Backward compatible: existing static SVG fallbacks remain fully functional where interactive components are omitted.
