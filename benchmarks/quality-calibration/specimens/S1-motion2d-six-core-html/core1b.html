DIAGNOSE → REPAIR

  • DIAGNOSE: At one instant 2 s after launch, may the x equation use t=2 s while the y equation uses another time?
    Wrong route: Independent x and y motions may use different elapsed times.
    REPAIR: No. Independence separates the axis equations; it does not give the same object two clocks.
  • DIAGNOSE: May x(2 s) be combined with y(3 s) to describe the particle's position?
    Wrong route: The x-motion and y-motion are two different objects that can be paired arbitrarily later.
    REPAIR: No. A plane state is a simultaneous pair. Recombine x(t) and y(t) only at the same t in the same frame.

Model response / rubric

Axes are kept separate while time/frame remain shared.: Correct component independence model.

Rejoin the inferential jump

Perpendicular components may be solved separately because each axis equation contains only that axis's quantities, but they still describe one object at one physical time.

BOUNDARY TEST

If a_x=0 but a_y is nonzero, may v_x stay constant while v_y changes?

Boundary answer

Yes. That is exactly what independent component evolution permits.

One component can change while the other does not.

DIAGNOSE → REPAIR

  • DIAGNOSE: If a=(10 i + 4 j) m/s², should both component equations use a=√116?
    Wrong route: The magnitude of acceleration should be inserted unchanged into both x and y equations.
    REPAIR: No. Use a_x=10 only in the x equation and a_y=4 only in the y equation; the magnitude is not either component.
  • DIAGNOSE: If a_x is constant but a_y changes with time, may the same constant-acceleration displacement formula be used exactly on y over the whole interval?
    Wrong route: If one acceleration component is constant, the constant-acceleration equations are automatically valid on both axes.
    REPAIR: No. Model validity is checked per axis. A constant a_x does not make a_y constant.
  • DIAGNOSE: If x-motion says an event occurs at t=3 s, what time belongs in the y equation for that same event?
    Wrong route: A time found from the x equation may be replaced by a different convenient time in the y equation.
    REPAIR: Use t=3 s. Both components describe the same event and therefore share one clock.

Model response / rubric

Each axis uses only its own signed initial values and acceleration while sharing the same time.: 2D component model use rather than a scalar-magnitude shortcut.

Rejoin the inferential jump

The one-dimensional constant-acceleration equations can be applied to each perpendicular component independently when a_x and a_y are each constant over the same interval.

BOUNDARY TEST

If a_y changes with time while a_x stays constant, may the constant-acceleration equations still be exact on both axes for the whole interval?

Boundary answer

No. The x relation may remain exact, but the y constant-acceleration relation is not exact over that interval.

Model validity is checked per component.

Immediately after a horizontal launch, which acceleration component is zero in the ideal model?

DIAGNOSE → REPAIR

  • DIAGNOSE: If a_x=0 after release, can v_x still be nonzero?
    Wrong route: A projectile needs a horizontal force to keep moving horizontally.
    REPAIR: Yes. Zero horizontal acceleration means horizontal velocity stays constant, not that it becomes zero.
  • DIAGNOSE: One second after a horizontal launch, is v_y still zero under gravity?
    Wrong route: A horizontal launch has no vertical velocity throughout the flight.
    REPAIR: No. u_y=0 only at release; a_y=-g makes v_y=-gt afterward.
  • DIAGNOSE: At the apex of an oblique projectile, which of v_x, v_y and a_y is zero?
    Wrong route: At the highest point the whole velocity and the acceleration are both zero.
    REPAIR: Only v_y is zero at that instant. v_x remains u_x and a_y remains -g.
  • DIAGNOSE: A ball launched from a roof lands on the ground below. May the same-height time-of-flight shortcut be used without checking the vertical displacement?
    Wrong route: Same-height flight formulas may be used whenever the question is about a projectile range or flight time.
    REPAIR: No. Same-height shortcuts require Delta y=0 between launch and landing. For unequal heights, solve the vertical position condition.
  • DIAGNOSE: On ascent and descent at the same height, how do the horizontal and vertical velocity components compare?
    Wrong route: At two points of the same height on an ideal trajectory, the velocity vectors are identical.
    REPAIR: v_x is the same, while v_y has equal magnitude and opposite sign; the speed matches but the velocity vector does not.
  • DIAGNOSE: If the horizontal launch speed doubles from the same height, does the ideal fall time change?
    Wrong route: Horizontal speed determines how long a horizontally launched object takes to fall.
    REPAIR: No. The vertical position equation determines the fall time; horizontal speed changes the range, not the fall time.

Model response / rubric

The learner selects gravity-only free flight, uses a_x=0/a_y=-g and one common time before calculating any named projectile quantity.: Projectile model selection rather than formula recall.

Rejoin the inferential jump

After release in the ideal near-Earth model, projectile motion is not a new set of laws: it is the same component kinematics with a_x=0 and a_y=-g (for +y upward).

BOUNDARY TEST

A launched object continues under significant horizontal thrust after release. May the standard a_x=0 projectile specialization be used?

Boundary answer

No. The object is not in gravity-only free flight; its horizontal acceleration is not zero under that model.

Projectile equations are conditional consequences of a declared force/model state.

  • DIAGNOSE: If K is proportional to v squared, what speed-squared fraction corresponds to a 50% energy retention?
    Wrong route: If half the kinetic energy remains, the speed becomes half.
    REPAIR: The speed squared becomes one half; the speed becomes 1/sqrt(2) of its previous value.

Close the first flight at impact, convert the retained energy to post-bounce speed squared, resolve the new vertical component, then use the standard height relation.

Boundary answer

No. Its post-bounce vertical component is zero, so the next rise height is zero.

The post-impact vertical component, not total speed, sets maximum rise.
