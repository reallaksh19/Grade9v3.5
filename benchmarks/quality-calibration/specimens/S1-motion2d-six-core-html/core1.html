Motion in 2D — Projectile Motion: Standard Model and Modified-Dynamics Demand

Compact semantic orientation from canonical truth, followed by an explicitly labelled extension map.

Canonical authority: PKG-PHY-KIN-2D-MOTION. Explicit demand extensions are CANDIDATE records and are labelled EXTENSION.

Scope and conventions

One plane-motion event is described in one declared Cartesian frame and one shared clock. Constant-acceleration relations are applied per component only when their model conditions hold. The projectile specialization is selected from retained forces before consequences are used.

Core1 orients; it does not turn source questions into academic authority and it does not replace the detailed Core1A/Core1B construction.

Canonical

Split one plane-motion event into independent x/y components with one clock

Hard transition: Perpendicular components may be solved separately because each axis equation contains only that axis's quantities, but they still describe one object at one physical time.

Representation: REP-KIN-2D-SHARED-CLOCK

Exit: A particle has x-velocity 6 m/s and y-velocity -8 m/s at t=3 s. Explain what 'independent components' means and what must remain shared between the x and y descriptions.

Canonical

Apply constant-acceleration kinematics component by component

Hard transition: The one-dimensional constant-acceleration equations can be applied to each perpendicular component independently when a_x and a_y are each constant over the same interval.

Representation: REP-KIN-2D-SHARED-CLOCK, REP-KIN-2D-EVENT-CLOCK

Exit: A particle starts with u=(0,5) m/s and constant a=(10,4) m/s². Set up the x and y position equations at common time t without solving a particular numerical t.

Canonical

Select the gravity-only projectile model before using projectile consequences

Hard transition: After release in the ideal near-Earth model, projectile motion is not a new set of laws: it is the same component kinematics with a_x=0 and a_y=-g (for +y upward).

Representation: REP-KIN-2D-SHARED-CLOCK, REP-KIN-2D-EVENT-CLOCK, REP-KIN-2D-PROJECTILE-MODEL

Exit: A stone is launched horizontally from a cliff with speed u. With +y upward and air resistance neglected, write its component acceleration, velocity and displacement relations after release and explain why one common t is used.
