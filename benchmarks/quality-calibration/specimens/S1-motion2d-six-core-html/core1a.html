Motion in 2D — Projectile Motion: Standard Model and Modified-Dynamics Demand

Detailed declarative teaching: canonical R1–R3 first, then the five labelled extensions.

Canonical authority: PKG-PHY-KIN-2D-MOTION. Explicit demand extensions are CANDIDATE records and are labelled EXTENSION.

Canonical

Split one plane-motion event into independent x/y components with one clock

Entry assumptions

  • Can read signed vector components in a declared x-y frame.

Inferential jump

Perpendicular components may be solved separately because each axis equation contains only that axis's quantities, but they still describe one object at one physical time.

Stepwise construction

  1. Choose one fixed x-y frame, one origin and one time origin for the whole plane-motion event.
    Why valid: A component value is meaningful only after its frame and sign convention are fixed.
    Output: one declared frame, origin, axis orientation and t=0
  2. Represent position, velocity and acceleration as signed x and y components in that same frame.
    Why valid: A plane vector is completely represented by its perpendicular Cartesian components once the frame is declared.
    Output: signed component state (x,y), (v_x,v_y), (a_x,a_y)
  3. Keep x-quantities in the x description and y-quantities in the y description while using one shared elapsed time.
    Why valid: The perpendicular component equations are independent in Cartesian kinematics, but both describe the same object during the same physical interval.
    Output: two axis histories coupled by one clock
  4. Recombine only component values that refer to the same frame and the same instant.
    Why valid: Mixing x at one time with y at another does not describe any single physical state of the object.
    Output: one physically valid plane state reconstructed from simultaneous components

Representation bridge

Canonical representation: REP-KIN-2D-SHARED-CLOCK; use the linked canonical explorer where supplied.

Worked conceptual anchor

A particle has v_x=6 m/s and v_y=-8 m/s at t=3 s. What makes these components one physical state?

  1. Use one declared x-y frame.
  2. Keep the same t=3 s for both components.
  3. Recombine only simultaneous components.

Result: The state is v=(6,-8) m/s at one shared instant.

Provenance: AUTHORED_PEDAGOGICAL

Plausible wrong path: Independent x and y motions may use different elapsed times.
Diagnostic: At one instant 2 s after launch, may the x equation use t=2 s while the y equation uses another time?
Repair: No. Independence separates the axis equations; it does not give the same object two clocks.
Plausible wrong path: The x-motion and y-motion are two different objects that can be paired arbitrarily later.
Diagnostic: May x(2 s) be combined with y(3 s) to describe the particle's position?
Repair: No. A plane state is a simultaneous pair. Recombine x(t) and y(t) only at the same t in the same frame.

Independent checks and limits

None supplied by the governed record.

Exit task

A particle has x-velocity 6 m/s and y-velocity -8 m/s at t=3 s. Explain what 'independent components' means and what must remain shared between the x and y descriptions.

Model answer

The x and y component equations are solved separately in the same frame, but both describe the same particle at the same t=3 s.

  1. Keep x quantities in the x equation and y quantities in the y equation.
  2. Use one common elapsed time for the same physical instant.
  3. Recombine components only after each axis is handled consistently.

Both component values must refer to the same frame and same instant.

Canonical

Apply constant-acceleration kinematics component by component

Entry assumptions

  • Can use the existing one-dimensional constant-acceleration model.
  • Can keep x/y components separate with one common time.

Inferential jump

The one-dimensional constant-acceleration equations can be applied to each perpendicular component independently when a_x and a_y are each constant over the same interval.

Stepwise construction

  1. Check separately whether a_x and a_y are constant over the interval before choosing constant-acceleration equations on either axis.
    Why valid: The familiar one-dimensional kinematic relations are exact only on an axis whose acceleration component is constant over the interval.
    Output: per-axis model-validity decision
  2. Apply the one-dimensional constant-acceleration relations independently to x and y using only that axis's signed values and the same t.
    Why valid: Each Cartesian component obeys the same one-dimensional relation when its acceleration component is constant.
    Output: v_x=u_x+a_x t; v_y=u_y+a_y t; Delta x=u_x t+0.5a_x t^2; Delta y=u_y t+0.5a_y t^2
  3. If one axis determines an event time, reuse that same time on the other axis before recombining and checking the plane state.
    Why valid: The event occurs once for the object; a time obtained from one component is the clock value for every component at that same event.
    Output: event time transferred across axes, then one checked plane state

Worked conceptual anchor

With u=(4,6) m/s and a=(0,-2) m/s², find v after 2 s.

  1. Apply v_x=u_x+a_x t.
  2. Apply v_y=u_y+a_y t.
  3. Recombine the simultaneous components.

Result: v=(4,2) m/s.

Provenance: AUTHORED_PEDAGOGICAL

Plausible wrong path: The magnitude of acceleration should be inserted unchanged into both x and y equations.
Diagnostic: If a=(10 i + 4 j) m/s², should both component equations use a=√116?
Repair: No. Use a_x=10 only in the x equation and a_y=4 only in the y equation; the magnitude is not either component.
Plausible wrong path: If one acceleration component is constant, the constant-acceleration equations are automatically valid on both axes.
Diagnostic: If a_x is constant but a_y changes with time, may the same constant-acceleration displacement formula be used exactly on y over the whole interval?
Repair: No. Model validity is checked per axis. A constant a_x does not make a_y constant.
Plausible wrong path: A time found from the x equation may be replaced by a different convenient time in the y equation.
Diagnostic: If x-motion says an event occurs at t=3 s, what time belongs in the y equation for that same event?
Repair: Use t=3 s. Both components describe the same event and therefore share one clock.

Independent checks and limits

  • Units match velocity on both equations.
  • If a_x=0 then v_x stays constant; likewise for y.
  • Every term has length units.
  • Setting one acceleration component to zero reduces that axis to uniform motion.

Exit task

A particle starts with u=(0,5) m/s and constant a=(10,4) m/s². Set up the x and y position equations at common time t without solving a particular numerical t.

Model answer

Use Delta x=0*t+0.5(10)t² and Delta y=5t+0.5(4)t² with the same t.

  1. Read signed component initial velocities and accelerations.
  2. Apply the 1D constant-acceleration displacement relation separately.
  3. Keep one common elapsed time.

Units are metres on both displacements and no x quantity appears in the y equation or vice versa.

Canonical

Select the gravity-only projectile model before using projectile consequences

Entry assumptions

  • Can solve 2D constant-acceleration component equations.
  • If an oblique launch angle is given, angle-based vector decomposition is available as a separate prerequisite for that question.

Inferential jump

After release in the ideal near-Earth model, projectile motion is not a new set of laws: it is the same component kinematics with a_x=0 and a_y=-g (for +y upward).

Stepwise construction

  1. Decide whether the object is in ideal near-Earth free flight after release; neglect air resistance, declare +y, then set a_x=0 and a_y=-g.
    Why valid: The standard projectile equations are a conditional specialization of 2D constant acceleration, not an automatic label for every launched object.
    Output: gravity-only projectile acceleration state
  2. Use supplied or separately resolved u_x and u_y with one common t in the horizontal and vertical component equations.
    Why valid: Horizontal, oblique and downward/upward initial components change the initial state, not the gravity-only model.
    Output: v_x=u_x; v_y=u_y-g t; Delta x=u_x t; Delta y=u_y t-0.5g t^2
  3. Translate the requested event into the component condition that defines it before solving for time.
    Why valid: Apex, same-height return, ground impact and a specified later instant are different events; each is identified by a different component condition.
    Output: event condition chosen before calculation
  4. For an apex event, set v_y=0 while keeping v_x=u_x and a_y=-g.
    Why valid: At the highest point only the vertical velocity component is momentarily zero; gravity still accelerates downward and horizontal motion continues.
    Output: apex condition v_y=0 with nonzero horizontal velocity and nonzero downward acceleration
  5. For a return to the launch height, set Delta y=0 and treat any same-height flight-time/range shortcut as conditional on that equality.
    Why valid: The shortcut follows from the vertical displacement returning to its initial value; it is not valid when the landing height differs.
    Output: same-height event condition and its validity boundary
  6. For any unequal-height landing, use the actual Delta y=y_f-y_i in the vertical position equation and retain the actual u_y; for a horizontal launch specifically, set u_y=0, then obtain the event time vertically and share it with x.
    Why valid: Initial vertical velocity and landing displacement describe different facts. The landing event is fixed by the actual vertical geometry, while u_y=0 is only the horizontal-launch initial condition.
    Output: Delta y=y_f-y_i=u_y t_event-0.5g t_event^2; for horizontal launch u_y=0; reuse the solved t_event on x
  7. At the selected event time, reconstruct the requested velocity, speed, direction, displacement or range from simultaneous components and check qualitative limits.
    Why valid: The reported projectile result is a consequence of one component model and one event, so its components must refer to the same instant and satisfy a_x=0, a_y=-g.
    Output: checked projectile consequence at one physical event

Worked conceptual anchor

A ball is released into free flight with u_x=8 m/s and u_y=6 m/s. State the acceleration model.

  1. Check retained forces after release.
  2. Neglect drag as stated.
  3. Use a_x=0 and a_y=-g.

Result: The gravity-only projectile model is licensed.

Provenance: AUTHORED_PEDAGOGICAL

Plausible wrong path: A projectile needs a horizontal force to keep moving horizontally.
Diagnostic: If a_x=0 after release, can v_x still be nonzero?
Repair: Yes. Zero horizontal acceleration means horizontal velocity stays constant, not that it becomes zero.
Plausible wrong path: A horizontal launch has no vertical velocity throughout the flight.
Diagnostic: One second after a horizontal launch, is v_y still zero under gravity?
Repair: No. u_y=0 only at release; a_y=-g makes v_y=-gt afterward.
Plausible wrong path: At the highest point the whole velocity and the acceleration are both zero.
Diagnostic: At the apex of an oblique projectile, which of v_x, v_y and a_y is zero?
Repair: Only v_y is zero at that instant. v_x remains u_x and a_y remains -g.
Plausible wrong path: Same-height flight formulas may be used whenever the question is about a projectile range or flight time.
Diagnostic: A ball launched from a roof lands on the ground below. May the same-height time-of-flight shortcut be used without checking the vertical displacement?
Repair: No. Same-height shortcuts require Delta y=0 between launch and landing. For unequal heights, solve the vertical position condition.
Plausible wrong path: At two points of the same height on an ideal trajectory, the velocity vectors are identical.
Diagnostic: On ascent and descent at the same height, how do the horizontal and vertical velocity components compare?
Repair: v_x is the same, while v_y has equal magnitude and opposite sign; the speed matches but the velocity vector does not.
Plausible wrong path: Horizontal speed determines how long a horizontally launched object takes to fall.
Diagnostic: If the horizontal launch speed doubles from the same height, does the ideal fall time change?
Repair: No. The vertical position equation determines the fall time; horizontal speed changes the range, not the fall time.

Independent checks and limits

  • v_x is constant.
  • At the highest point of an oblique trajectory, v_y=0 but a_y remains -g.
  • Both component equations use the same t.

Exit task

A stone is launched horizontally from a cliff with speed u. With +y upward and air resistance neglected, write its component acceleration, velocity and displacement relations after release and explain why one common t is used.

Model answer

a_x=0, a_y=-g; v_x=u, v_y=-gt; Delta x=ut, Delta y=-0.5gt², all at the same elapsed time t.

  1. After release only gravity acts in the ideal model.
  2. Gravity has no horizontal component in the chosen frame.
  3. Both component coordinates describe the same stone at the same instant.

Horizontal velocity remains constant while downward speed magnitude grows with time.

EXTENSION

EXTENSION — instantaneous velocity direction from x(t) and y(t)

Entry assumptions

  • Can interpret x(t) and y(t) as one particle with one shared time.
  • Has introductory meaning of derivative as instantaneous rate of change.

Inferential jump

The direction of motion at an instant comes from the tangent velocity (dx/dt, dy/dt), not from the position vector (x,y).

Stepwise construction

  1. Identify that the requested direction is the direction of instantaneous velocity, not the direction from the origin to the particle.
    Why valid: Velocity is the instantaneous rate of change of position; position direction answers a different question.
    Output: target vector is v(t)
  2. Differentiate x(t) and y(t) separately to obtain v_x(t) and v_y(t).
    Why valid: Cartesian component derivatives give the components of the velocity vector.
    Output: v_x=dx/dt and v_y=dy/dt
  3. Evaluate both velocity components at the same requested time and use their signed ratio to determine the direction.
    Why valid: The two components form one simultaneous velocity vector only at the same instant.
    Output: tan(theta)=v_y/v_x with quadrant checked
  4. Compare the velocity arrow with the local tangent to the trajectory and reject any answer based only on y/x.
    Why valid: Instantaneous velocity is tangent to the path while the position vector generally is not.
    Output: direction passes the tangent check

Representation bridge

Worked conceptual anchor

For x=4t and y=10t-t², find v at t=2 s.

  1. Differentiate both component positions.
  2. Evaluate at the same time.

Result: v=(4,6) m/s.

Provenance: AUTHORED_PEDAGOGICAL

Plausible wrong path: Use y/x at the requested time to get the direction of motion.
Diagnostic: Does y/x describe the tangent direction or only the direction of the position vector from the origin?
Repair: Differentiate first; use v_y/v_x for the velocity direction.

Independent checks and limits

  • Velocity direction must be tangent to the path.
  • Both component values must use the same time.

Exit task

If x=5t and y=12t-t^2, state the operations needed to find the velocity direction at t=2 s.

Model answer

Differentiate to get v_x=5 and v_y=12-2t, evaluate both at t=2, then use the signed component ratio and quadrant.

  1. Use derivatives, not x and y themselves.
  2. Evaluate both at one time.
  3. Use the velocity components for direction.

The resulting velocity arrow must be tangent to the path.

EXTENSION — projectile rebound after an energy-changing impact

Entry assumptions

  • Can use the gravity-only projectile maximum-height relation after launch.
  • Can resolve a speed into components.

Inferential jump

A stated kinetic-energy retention fraction acts on v^2; after the collision creates a new launch state, only that new vertical component controls the next rise height.

Stepwise construction

  1. Treat impact as an event boundary: pre-impact projectile flight ends and a new post-impact launch state begins.
    Why valid: An impulsive collision changes velocity over a short event and the next free-flight segment starts from the post-impact state.
    Output: post-impact launch state
  2. Convert K_after=f K_before into v_after^2=f v_before^2 for unchanged mass.
    Why valid: K=1/2 mv^2, so an energy fraction multiplies speed squared.
    Output: v_after^2=f v_before^2
  3. Resolve the post-bounce speed using its stated direction and use the upward component in H=v_y^2/(2g).
    Why valid: Maximum rise after the bounce depends on the post-bounce vertical kinetic state under gravity-only flight.
    Output: H_after=(v_after sin alpha)^2/(2g)
  4. Check that losing energy cannot create a rebound height inconsistent with the retained-energy fraction and vertical-component fraction.
    Why valid: Energy and component fractions provide an independent bound on the height.
    Output: height scaling is physically bounded

Representation bridge

Worked conceptual anchor

A rebound retains 49% of kinetic energy. What fraction of the pre-impact speed remains?

  1. Use K proportional to v².
  2. Take the positive square root of 0.49.

Result: 70% of the speed remains.

Provenance: AUTHORED_PEDAGOGICAL

Plausible wrong path: If half the kinetic energy remains, the speed becomes half.
Diagnostic: If K is proportional to v squared, what speed-squared fraction corresponds to a 50% energy retention?
Repair: The speed squared becomes one half; the speed becomes 1/sqrt(2) of its previous value.

Independent checks and limits

  • For 0<=f<=1, retained speed squared cannot exceed the pre-impact value.
  • If alpha=0, the new rise height is zero.

Exit task

A ball keeps 64% of its kinetic energy and rebounds at an angle alpha. State the chain needed to find its new maximum height.

Model answer

Use v_after^2=0.64 v_before^2, take v_y=v_after sin alpha, then H=v_y^2/(2g).

  1. Translate energy fraction to speed squared.
  2. Resolve the new launch direction.
  3. Use the vertical component for height.

The result scales with 0.64 sin^2(alpha) relative to a same-speed vertical-height reference.

EXTENSION — projectile motion when gravity changes after the apex

Entry assumptions

  • Can identify the apex by v_y=0.
  • Can solve vertical constant-acceleration motion from a known state.

Inferential jump

A change in constant gravity creates two kinematic stages joined by one boundary state; position and velocity at the apex are inherited by the second stage while acceleration changes.

Stepwise construction

  1. Split the trajectory at the apex boundary and label stage 1 with g_1 and stage 2 with g_2.
    Why valid: The model assumption changes at one event, so one constant-acceleration equation cannot span both regions.
    Output: two-stage event model
  2. Use the ordinary projectile model only up to the apex to determine the apex position and horizontal velocity.
    Why valid: Before the boundary, gravity is g_1 and horizontal acceleration is zero.
    Output: apex state (x_A,H,v_x,0)
  3. Start stage 2 from the apex with v_y=0 and downward acceleration g_2; compute the descent time from H=(1/2)g_2 t_2^2.
    Why valid: The second stage is constant-acceleration motion with its own acceleration but inherited initial state.
    Output: t_2=sqrt(2H/g_2)
  4. Check that increasing post-apex gravity shortens only the descent portion and therefore shortens only the post-apex horizontal distance.
    Why valid: v_x remains unchanged at the boundary while the fall time changes.
    Output: range ratio lies between apex fraction and ordinary full range for stronger gravity

Representation bridge

Worked conceptual anchor

From the same apex height, gravity doubles after the apex. How does descent time change?

  1. Preserve the apex height and v_y=0.
  2. Use t=sqrt(2H/g₂).

Result: The descent time becomes 1/sqrt(2) of the ordinary value.

Provenance: AUTHORED_PEDAGOGICAL

Plausible wrong path: Once gravity changes at the apex, recompute the entire trajectory using the new gravity.
Diagnostic: Did the projectile experience g_2 before it reached the apex?
Repair: No. Preserve the stage-1 apex state, then apply g_2 only to stage 2.

Independent checks and limits

  • If g_2=g_1, recover the ordinary symmetric projectile result.
  • Larger g_2 gives shorter descent time from the same height.

Exit task

If post-apex gravity is four times larger, how does the descent time from the same apex height compare with the ordinary descent time?

Model answer

It is half as long because t is proportional to 1/sqrt(g) for a fall from rest through the same height.

  1. The apex height is already fixed by stage 1.
  2. Stage 2 starts with v_y=0.
  3. t=sqrt(2H/g_2).

Stronger gravity must reduce, not increase, the descent time.

EXTENSION — trajectory equation through a specified point

Entry assumptions

  • Can write x(t) and y(t) for a gravity-only projectile.
  • Can resolve an initial speed into horizontal and vertical components.

Inferential jump

Eliminating the common time creates a path equation y(x), but passing through a point and locating the apex are separate decisions.

Stepwise construction

  1. Confirm the gravity-only projectile assumptions before eliminating time.
    Why valid: The trajectory equation is a consequence of the standard projectile model, not a universal curve.
    Output: projectile model licensed
  2. Use x=u cos(theta)t to eliminate t from y=u sin(theta)t-(1/2)gt^2.
    Why valid: Both component equations describe the same event time, so eliminating that common t is valid.
    Output: y=x tan(theta)-g x^2/[2u^2 cos^2(theta)]
  3. Substitute the specified point coordinates to constrain u and theta.
    Why valid: A point lies on the trajectory only if its coordinates satisfy the path equation.
    Output: point constraint on launch parameters
  4. Use v_y at the point or the local trajectory slope to decide whether the projectile is rising or falling there.
    Why valid: Passing through P does not by itself reveal whether P occurs before or after the apex.
    Output: apex-relative position classified

Representation bridge

Worked conceptual anchor

For theta=45°, what extra test tells whether a known point on the path is after the apex?

  1. Use the path equation for membership.
  2. Check v_y or dy/dx at the point.

Result: A negative vertical velocity or slope places the point after the apex.

Provenance: AUTHORED_PEDAGOGICAL

Plausible wrong path: If a point satisfies the trajectory equation, the apex must be after that point.
Diagnostic: Can a projectile pass through the same height on both its rising and falling branches?
Repair: Yes. Use v_y or slope at the point to determine the branch.

Independent checks and limits

  • At x=0 the equation gives y=0 for launch from origin.
  • The gravity term lowers the path below the straight-line ray x tan(theta).

Exit task

What two checks are needed when asked whether a projectile passes through P and has already crossed its apex there?

Model answer

First impose P in the trajectory equation; then use v_y or local slope at P to determine whether the path is descending.

  1. Point membership and branch are separate.
  2. Use the trajectory equation for membership.
  3. Use velocity/slope for apex position.

A negative local slope or v_y indicates the apex is already behind the projectile.

EXTENSION

EXTENSION — projectile motion with linear drag

Entry assumptions

  • Can apply Newton's second law to one component.
  • Understands an exponential decay law at a qualitative level or can follow its supplied solution.

Inferential jump

With F_drag=-cv, horizontal acceleration is proportional to -v_x rather than zero; solving the differential equation gives exponential velocity decay and displacement must be integrated from that velocity.

Stepwise construction

  1. Reject the standard a_x=0 projectile specialization when linear drag F=-cv is retained.
    Why valid: Drag has a horizontal component whenever v_x is nonzero, so horizontal acceleration is not zero.
    Output: modified horizontal model selected
  2. Write Newton's second law in x: m dv_x/dt=-c v_x.
    Why valid: Linear drag opposes the instantaneous velocity and is proportional to its component.
    Output: dv_x/dt=-(c/m)v_x
  3. Use the exponential solution v_x(t)=v_x0 exp(-ct/m) and integrate it over time.
    Why valid: The first-order decay equation has an exponential solution; displacement is the time integral of velocity.
    Output: x-x_0=(m/c)v_x0[1-exp(-ct/m)]
  4. Check that c→0 recovers x-x_0≈v_x0 t and that drag distance is smaller than the no-drag distance for c>0.
    Why valid: The limiting model and inequality provide independent checks.
    Output: solution recovers no-drag limit and reduced range

Representation bridge

Worked conceptual anchor

If m/c=3 s, what fraction of initial horizontal speed remains after 3 s?

  1. Use v_x/v_x0=e^{-t/(m/c)}.
  2. Set t=m/c.

Result: e^{-1}, about 0.368, remains.

Provenance: AUTHORED_PEDAGOGICAL

Plausible wrong path: Use x=v_x0 t because projectile horizontal velocity is always constant.
Diagnostic: If the drag force has an x component -c v_x, can a_x still be zero?
Repair: No. Solve the velocity-dependent equation first, then integrate v_x(t).

Independent checks and limits

  • As c approaches zero, Δx approaches v_x0 t.
  • For c>0, Δx<v_x0 t for t>0.

Exit task

For m dv_x/dt=-c v_x, state v_x(t), the horizontal displacement from 0 to t, and one limiting check.

Model answer

v_x=v_x0 e^{-ct/m}; Δx=(m/c)v_x0(1-e^{-ct/m}); as c approaches zero, Δx approaches v_x0 t.

  1. Solve the linear decay equation.
  2. Integrate velocity.
  3. Check the zero-drag limit.

For positive c and t, the distance is less than v_x0 t.
