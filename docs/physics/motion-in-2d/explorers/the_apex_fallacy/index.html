THE "CARTOON PHYSICS" HOVER TEST & 90° BOUNDARY

THOUGHT EXPERIMENT: What if aᵢ = 0 at the peak?

If acceleration were zero whenever velocity is zero (vᵢ = 0 ⇒ aᵢ = 0), then Δvᵢ = 0 · Δt = 0. The velocity would never change from zero. The projectile would freeze and hover in mid-air permanently!

Descent occurs precisely because gravity never takes a break at the apex.
BOUNDARY CASE: θ = 90° (Vertical Launch)

When launched straight up, vₓ = 0 everywhere. At the peak, vᵢ = 0, so total speed is momentarily zero.

Yet aᵢ = −9.81 m/s² downward! This boundary case definitively proves: zero instantaneous velocity does NOT imply zero acceleration.
