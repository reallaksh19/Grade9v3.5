SAME HEIGHT, SAME SPEED ≠ SAME VELOCITY

Equal elevation gives |v_A| = |v_B| (speed), but v_A ≠ v_B (vectors). Direction has inverted!

FALLACY "Since height is identical, velocity is identical." → FALSE.
INVARIANT Magnitudes equal: |v_A| = |v_B|. Directions opposite: v_By = −v_Ay.
