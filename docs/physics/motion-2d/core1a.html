Motion in a Plane: Projectiles & Orthogonal Components

Master two-dimensional kinematics through orthogonal decomposition: independent horizontal uniform motion (\(a_x = 0\)) and vertical free-fall acceleration (\(a_y = -g\)) linked by a shared clock (\(t\)).

Unit 1 · Orthogonal Independence & Shared Clock

What is Happening?

A projectile is launched with velocity \(u\) at an angle \(\theta\). The horizontal and vertical motions unfold simultaneously without cross-talk or force interference.

Key Idea

Time \(t\) is the master scalar parameter binding the two independent 1D motions: \(x(t) = (u\cos\theta)t\) and \(y(t) = (u\sin\theta)t - \frac{1}{2}gt^2\).

Horizontal Axis:   \(u_x = u\cos\theta, \quad a_x = 0, \quad v_x(t) = u\cos\theta, \quad x(t) = u_x t\)
Vertical Axis:   \(u_y = u\sin\theta, \quad a_y = -g, \quad v_y(t) = u\sin\theta - gt, \quad y(t) = u_y t - \frac{1}{2}gt^2\)
Trajectory Equation:   \(y = x\tan\theta - \frac{gx^2}{2u^2\cos^2\theta} \quad (\text{Cartesian Parabola})\)

The 4 Essential Ground-to-Ground Formulas

  1. Time of Flight (\(T\)): Set \(y = 0 \implies t(u\sin\theta - \frac{1}{2}gt) = 0 \implies T = \frac{2u\sin\theta}{g}\).
  2. Maximum Height (\(H_{\max}\)): At the apex, vertical velocity vanishes (\(v_y = 0\)): \(0 = u_y^2 - 2gH \implies H = \frac{u^2\sin^2\theta}{2g}\).
  3. Horizontal Range (\(R\)): Substitute \(t = T\) into horizontal motion: \(R = u_x T = \frac{u^2\sin 2\theta}{g}\).
  4. Complementary Angle Symmetries: Angles \(\theta\) and \((90^\circ - \theta)\) yield identical horizontal ranges: \(R(\theta) = R(90^\circ - \theta)\).
⚠️ Critical Trap: The Apex Velocity Fallacy

Never state that velocity is zero at the highest point! At the apex, only vertical velocity vanishes (\(v_y = 0\)). The horizontal velocity persists: \(\vec{v}_{\text{apex}} = (u\cos\theta)\hat{i} \ne 0\). The acceleration at apex is still \(-g\hat{j}\), NOT zero.

Unit 2 · Asymmetric Flight & Elevated Clifftop Launches

When launched from height \(h\) above ground (\(y(0) = h\)), landing occurs when \(y(t) = 0 \implies h + u_y t - \frac{1}{2}gt^2 = 0\). Time of flight is solved via the quadratic formula:

\[t_{\text{land}} = \frac{u\sin\theta + \sqrt{u^2\sin^2\theta + 2gh}}{g}\]

Worked Problem: Horizontal Cliff Launch

A ball is rolled horizontally off a clifftop of height \(h = 45\,\text{m}\) with speed \(u = 20\,\text{m/s}\). Take \(g = 10\,\text{m/s}^2\).

  1. Vertical Time: \(u_y = 0 \implies h = \frac{1}{2}gt^2 \implies 45 = 5t^2 \implies t = 3\,\text{s}\).
  2. Horizontal Drift (Range): \(x = u_x t = 20 \times 3 = 60\,\text{m}\).
  3. Impact Velocity: \(v_x = 20\,\text{m/s}\), \(v_y = -gt = -30\,\text{m/s}\). Net speed \(v = \sqrt{20^2 + (-30)^2} = \sqrt{1300} \approx 36.06\,\text{m/s}\).
  4. Impact Angle: \(\tan\phi = \frac{|v_y|}{v_x} = \frac{30}{20} = 1.5 \implies \phi \approx 56.3^\circ\) below horizontal.
