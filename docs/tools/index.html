Browsable surfaces over this repository's governed data. Everything here is generated from the library, the gate registries and the subject contracts by Shared/tools/build_web_data.py; nothing on these pages is authoritative in itself.

Static and offline-safe: data arrives as a script assignment rather than a fetch, so these pages work opened directly from disk.

Governance invariants these surfaces respect

  • Machine checks establish structure, custody and supported computation. They do not establish that an explanation teaches.
  • A board-scope claim without an exact binding reads HELD, never assumed authority.
  • A product the library cannot support is reported unsupported, not padded.
  • No page here grants learner release, academic acceptance or measured fit.
