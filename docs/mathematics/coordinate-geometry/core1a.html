The Cartesian Coordinate Plane & Four Quadrants

The Cartesian plane is formed by two mutually perpendicular real number lines intersecting at their common zero point, known as the origin $O(0, 0)$.

$$ ext{Plane } \mathbb{R}^2 = ext{Quadrant I } \cup ext{II } \cup ext{III } \cup ext{IV } \cup ext{Axes}$$
  • Horizontal Axis ($X$-axis): Directed from negative infinity on the left ($X'$) to positive infinity on the right ($X$).
  • Vertical Axis ($Y$-axis): Directed from negative infinity at the bottom ($Y'$) to positive infinity at the top ($Y$).
  • Quadrant Sign Conventions
    Four Quadrants: Numbered counter-clockwise starting from the top-right:
    • Quadrant I: $(+x, +y)$ — both coordinates positive
    • Quadrant II: $(-x, +y)$ — negative abscissa, positive ordinate
    • Quadrant III: $(-x, -y)$ — both coordinates negative
    • Quadrant IV: $(+x, -y)$ — positive abscissa, negative ordinate

Worked Anchor (m2 Page 15 Item 1)

Problem: Determine the quadrant or axis for: (a) $(3, -2)$, (b) $(-4, 5)$, (c) $(-2, -3)$, (d) $(5, 0)$, (e) $(0, 4)$.

  1. $(3, -2)$: $x > 0, y < 0 \implies \mathbf{ ext{Quadrant IV}}$.
  2. $(-4, 5)$: $x < 0, y > 0 \implies \mathbf{ ext{Quadrant II}}$.
  3. $(-2, -3)$: $x < 0, y < 0 \implies \mathbf{ ext{Quadrant III}}$.
  4. $(5, 0)$: $y = 0 \implies \mathbf{ ext{On positive } X ext{-axis}}$ (axes belong to no quadrant).
  5. $(0, 4)$: $x = 0 \implies \mathbf{ ext{On positive } Y ext{-axis}}$.

Abscissa and Ordinate: Orthogonal Projections

Every point $P(x, y)$ in the plane represents a unique pair of signed perpendicular distances to the coordinate axes.

$$ ext{Abscissa } = x = ext{Signed distance from } Y ext{-axis}$$ $$ ext{Ordinate } = y = ext{Signed distance from } X ext{-axis}$$
  • Foot on $X$-axis: Drop a perpendicular from $P(x, y)$ to the horizontal axis. It meets at point $M(x, 0)$.
  • Foot on $Y$-axis: Drop a perpendicular from $P(x, y)$ to the vertical axis. It meets at point $N(0, y)$.
  • Crux Definition
    Order Matters: The ordered pair $(x, y)$ is not interchangeable. $(3, 8) eq (8, 3)$. Abscissa always precedes ordinate.

Worked Anchor (m2 Page 17 FIB-02)

Problem: State the signs of the abscissa and ordinate of a point in the second quadrant.

  1. Second quadrant lies to the left of the $Y$-axis $\implies x < 0$ (abscissa is negative, $-$).
  2. Second quadrant lies above the $X$-axis $\implies y > 0$ (ordinate is positive, $+$).
  3. Official key: $-, +$.

Axis Boundary Invariants

The coordinate axes themselves do not belong to any quadrant; they serve as boundaries where one coordinate vanishes identically.

$$ ext{Point on } X ext{-axis} \iff y = 0 \quad [P(x, 0)]$$ $$ ext{Point on } Y ext{-axis} \iff x = 0 \quad [P(0, y)]$$
  • Equation of the $X$-axis: The equation of the horizontal axis is $y = 0$, because every point on it has zero vertical height.
  • Equation of the $Y$-axis: The equation of the vertical axis is $x = 0$, because every point on it has zero horizontal displacement.
  • Intersection
    The Origin: The only point belonging simultaneously to both axes is $O(0, 0)$, where both $x = 0$ and $y = 0$.

Axis Boundary Invariants

• (5, 0) → On positive $X$-axis

• (-3, 0) → On negative $X$-axis

• (0, 4) → On positive $Y$-axis

• (0, -6) → On negative $Y$-axis

• (0, 0) → The Origin

Metric Projections & Distances from Axes

Physical geometric distances are strictly non-negative real quantities, computed via absolute values of coordinates.

$$ ext{Dist}(P, X ext{-axis}) = |y| \qquad ext{Dist}(P, Y ext{-axis}) = |x|$$ $$ ext{Dist}(P, ext{Origin } O) = \sqrt{x^2 + y^2}$$
  • Distance from $X$-axis: Equals the absolute value of the ordinate ($|y|$), regardless of quadrant.
  • Distance from $Y$-axis: Equals the absolute value of the abscissa ($|x|$).
  • Crux Pitfall
    Common Inversion Mistake: Learners frequently confuse distance from $X$-axis with $x$. Remember: distance to the horizontal axis is the vertical distance, which is $|y|$.

Worked Anchor (m2 Page 15 Item 2)

Problem: Find the distance of point $P(3, 8)$ from (i) $X$-axis, (ii) $Y$-axis.

  1. Distance from $X$-axis $= |y| = |8| = \mathbf{8}$.
  2. Distance from $Y$-axis $= |x| = |3| = \mathbf{3}$.

Follow-up: For point $Q(-5, -7)$: distance from $X$-axis is $|-7| = 7$; distance from $Y$-axis is $|-5| = 5$.

Geometric Figures in the Coordinate Plane

Plotting sets of ordered coordinates and joining them sequentially produces polygons whose geometric properties (lengths, areas, perpendicularities) can be verified algebraically.

$$ ext{Area}( ext{Rectangle}) = ext{base} imes ext{height} = |x_2 - x_1| imes |y_2 - y_1|$$
  • Horizontal Segment: Between $(x_1, y_0)$ and $(x_2, y_0)$, length is $|x_2 - x_1|$.
  • Vertical Segment: Between $(x_0, y_1)$ and $(x_0, y_2)$, length is $|y_2 - y_1|$.
  • Crux Identification
    Identifying Rectangles & Squares: Vertices with matching horizontal and vertical coordinates form right angles with axes, confirming rectangular boundaries.

Worked Anchor (m2 Page 15 Item 5)

Problem: Plot points $A(0, 0), B(5, 0), C(5, 4), D(0, 4)$ and identify the figure $ABCD$.

  1. Segment $AB$: along $X$-axis from $x=0$ to $x=5$, length $= 5$.
  2. Segment $BC$: vertical from $y=0$ to $y=4$ at $x=5$, length $= 4$.
  3. Segment $CD$: horizontal from $x=5$ to $x=0$ at $y=4$, length $= 5$.
  4. Segment $DA$: vertical from $y=4$ to $y=0$ at $x=0$, length $= 4$.
  5. Adjacent sides are perpendicular ($5 eq 4$), opposite sides are equal. Figure is a Rectangle with area $5 imes 4 = 20 ext{ sq units}$.
