Unit 1 of 5

The Bridge: Roots ⇄ Factors ⇄ Coefficients

What is happening?

A root $r$ is a numerical input making $P(r) = 0$. By the Factor Theorem, each root corresponds bijectively to a linear factor $(x - r)$. Expanding the product of all linear factors directly generates the polynomial coefficients.

Key Idea

Coefficients are not arbitrary numbers; each coefficient encodes an exact elementary symmetric combination of the roots with alternating signs: $-e_1, +e_2, -e_3, \dots$

$$(x - \alpha)(x - \beta)(x - \gamma) = x^3 - (\alpha + \beta + \gamma)x^2 + (\alpha\beta + \beta\gamma + \gamma\alpha)x - \alpha\beta\gamma = 0$$
  • Negative Roots: If a root is $-\frac{3}{2}$, the factor is $\left(x - \left(-\frac{3}{2} ight) ight) = \left(x + \frac{3}{2} ight)$.
  • Monic Reduction: For general cubic $Ax^3 + Bx^2 + Cx + D = 0$, always divide by the leading coefficient $A$: $\sum \alpha = -\frac{B}{A}, \quad \sum \alpha\beta = \frac{C}{A}, \quad \alpha\beta\gamma = -\frac{D}{A}$.
  • Crux Move
    Direct Match: When an unknown coefficient like $k$ in $x^3 - 5x^2 + kx + 8 = 0$ is sought for known roots $2, -1, 4$, compute the pairwise sum directly: $k = (2)(-1) + (-1)(4) + (4)(2) = -2 - 4 + 8 = 2$ without expanding the full cubic!

Unit 2 of 5

Recovering Missing Roots: The Auxiliary Quadratic

What is happening?

When a cubic's roots $\alpha, \beta, \gamma$ are partially known (e.g. given the partial sum $\alpha + \beta$), never guess individual roots. Use the total root sum to find $\gamma$, and the total product to find $\alpha\beta$.

Key Idea

$\alpha$ and $\beta$ are the exact two roots of the auxiliary quadratic equation: $t^2 - (\alpha + \beta)t + \alpha\beta = 0$.

$$t^2 - (\alpha + \beta)t + \alpha\beta = 0$$

Worked Model (Benchmark Section 5)

Problem: Let $\alpha, \beta, \gamma$ be roots of $x^3 - 5x^2 + 2x + 8 = 0$, with $\alpha + \beta = 3$. Find all three roots.

  1. Total sum is $5 \implies \gamma = 5 - (\alpha + \beta) = 5 - 3 = 2$.
  2. Total product is $-8 \implies \alpha\beta\gamma = -8 \implies \alpha\beta(2) = -8 \implies \alpha\beta = -4$.
  3. Form auxiliary quadratic: $t^2 - 3t - 4 = 0$.
  4. Factor: $(t - 4)(t + 1) = 0 \implies t = 4$ or $t = -1$.
  5. Roots are $\alpha = 4, \beta = -1, \gamma = 2$. Verified!

Unit 3 of 5

Symmetric Expressions Without Solving Polynomials

What is happening?

An algebraic expression is symmetric if swapping any two variables leaves the expression unchanged. Every symmetric polynomial in the roots can be uniquely expressed in terms of the elementary symmetric polynomials $e_1, e_2, e_3$.

Key Idea

Never solve for individual irrational or complex roots! Read $e_1, e_2, e_3$ from coefficients, then use algebraic squaring identities.

Fundamental Symmetric Identities:

  1. Sum of squares: $$\alpha^2 + \beta^2 + \gamma^2 = e_1^2 - 2e_2$$
  2. Pairwise product of squares: $$\alpha^2\beta^2 + \beta^2\gamma^2 + \gamma^2\alpha^2 = e_2^2 - 2e_1e_3$$
  3. Sum of reciprocals: $$\frac{1}{\alpha} + \frac{1}{\beta} + \frac{1}{\gamma} = \frac{\alpha\beta + \beta\gamma + \gamma\alpha}{\alpha\beta\gamma} = \frac{e_2}{e_3}$$
⚠️ Watch Out:

Remember that for a monic cubic $x^3 + ax^2 + bx + c = 0$, $e_1 = -a$, $e_2 = b$, but $e_3 = -c$. Neglecting the negative sign in $e_3$ is the most frequent exam pitfall!

Numerical Evaluation Model

For $x^3 - 3x^2 - 2x + 5 = 0$:

$e_1 = 3, \quad e_2 = -2, \quad e_3 = -5$

1. Compute $\alpha^2 + \beta^2 + \gamma^2$:

$$e_1^2 - 2e_2 = (3)^2 - 2(-2) = 9 + 4 = 13$$

2. Compute $\alpha^2\beta^2 + \beta^2\gamma^2 + \gamma^2\alpha^2$:

$$e_2^2 - 2e_1e_3 = (-2)^2 - 2(3)(-5) = 4 + 30 = 34$$

Unit 4 of 5

Newton Sums: Computing High Powers via Recurrences

What is happening?

When asked for high power sums $S_k = \alpha^k + \beta^k + \gamma^k + \delta^k$ (such as $\alpha^5 + \beta^5 + \gamma^5 + \delta^5$), finding roots is computationally impossible. Newton sums relate power sums directly to the polynomial coefficients.

Key Idea

For a monic polynomial $x^n + a_1x^{n-1} + \dots + a_n = 0$, the power sums satisfy startup relations for $k \le n$, and a linear constant-coefficient recurrence for $k \ge n+1$.

  • Startup Step 1: $S_1 + a_1 = 0 \implies S_1 = -a_1$.
  • Startup Step 2: $S_2 + a_1 S_1 + 2a_2 = 0 \implies S_2 = -a_1 S_1 - 2a_2$.
  • Startup Step 3: $S_3 + a_1 S_2 + a_2 S_1 + 3a_3 = 0$.
  • Startup Step 4: $S_4 + a_1 S_3 + a_2 S_2 + a_3 S_1 + 4a_4 = 0$.
  • Homogeneous Shift
    Higher Powers ($k \ge 5$): For any $n \ge 5$, $S_n + a_1 S_{n-1} + a_2 S_{n-2} + a_3 S_{n-3} + a_4 S_{n-4} = 0$.

Unit 5 of 5

Olympiad / JEE Advanced Worked Model: $S_5$ Calculation

Consider the quartic equation $x^4 - 2x^3 - x^2 + 2x = 0$ with roots $\alpha, \beta, \gamma, \delta$. Compute $S_5 = \alpha^5 + \beta^5 + \gamma^5 + \delta^5$.

1. Read Coefficients

$a_1 = -2, \quad a_2 = -1, \quad a_3 = 2, \quad a_4 = 0$

Compute Startup Power Sums:

  • $S_1 - 2 = 0 \implies S_1 = 2$
  • $S_2 - 2(2) + 2(-1) = 0 \implies S_2 - 4 - 2 = 0 \implies S_2 = 6$
  • $S_3 - 2(6) - 1(2) + 3(2) = 0 \implies S_3 - 12 - 2 + 6 = 0 \implies S_3 = 8$
  • $S_4 - 2(8) - 1(6) + 2(2) + 4(0) = 0 \implies S_4 - 16 - 6 + 4 = 0 \implies S_4 = 18$

2. Apply Recurrence for $n = 5$

The homogeneous recurrence gives:

$$S_5 - 2S_4 - 1S_3 + 2S_2 + 0S_1 = 0$$

Substitute known values:

$$S_5 - 2(18) - (8) + 2(6) = 0$$

$$S_5 - 36 - 8 + 12 = 0$$

$$S_5 - 32 = 0 \implies \mathbf{S_5 = 32}$$

Exact answer achieved in under 2 minutes without solving for any roots!
