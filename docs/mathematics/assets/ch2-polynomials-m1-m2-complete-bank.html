If $ax^2 + 2a^2x + b^3$ is divisible by $x + a$, then the relationship between $a$ and $b$ is _____.

Method / Note: Root is $x = -a$. Substitution gives $a(-a)^2 + 2a^2(-a) + b^3 = a^3 - 2a^3 + b^3 = -a^3 + b^3 = 0 \implies a = b$.

If $\dfrac{p}{q} + \dfrac{q}{p} = 2$, the value of $\left(\dfrac{p}{q}\right)^{23} + \left(\dfrac{q}{p}\right)^7$ is $2$.
Official Key / Solution: True
Method / Note: $\frac{p}{q} + \frac{q}{p} = 2 \implies \frac{p^2+q^2-2pq}{pq} = 0 \implies (p-q)^2 = 0 \implies p = q$. Thus $1^{23} + 1^7 = 2$.
Q-M2-P01-TF-02
m2.pdfPage 2.22True/False
If $p(x) = 2x^3 - 3x^2 + 5x - 4$ is divided by $(x - 2)$, then the remainder is $-10$.
Official Key / Solution: False
Method / Note: $p(2) = 2(8) - 3(4) + 5(2) - 4 = 16 - 12 + 10 - 4 = +10 \neq -10$.
Q-M2-P01-TF-03
m2.pdfPage 2.22True/False
The coefficient of $x^2y^2$ in the expansion of $(x + y)^4$ is $12$.
Official Key / Solution: False
Method / Note: By binomial expansion, the coefficient of $x^2y^2$ is $\binom{4}{2} = \frac{4 \times 3}{2} = 6 \neq 12$.
Q-M2-P01-TF-04
m2.pdfPage 2.22True/False
If $x^2 - 3x + 1 = 0$, then the value of $x^5 + \dfrac{1}{x^5}$ is $123$.
Official Key / Solution: True
Method / Note: $x + 1/x = 3$. Then $x^2 + 1/x^2 = 7$, $x^3 + 1/x^3 = 18$. $(x^2+1/x^2)(x^3+1/x^3) = x^5 + 1/x^5 + x + 1/x \implies 7 \times 18 = x^5 + 1/x^5 + 3 \implies x^5 + 1/x^5 = 126 - 3 = 123$.
