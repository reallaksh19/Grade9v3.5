Concept 1 of 6

Degree Classification & Like-Term Simplification

The degree of a polynomial in one variable is the highest exponent of the variable with a non-zero coefficient in its fully simplified form.

$$ ext{deg}\Big(\sum_{k=0}^n a_k x^k\Big) = n \quad ext{where } a_n eq 0$$
  • Combine All Like Powers: Terms with identical variable exponents must be algebraically grouped before inspecting powers.
  • Crux Distinction
    Inspect Non-Zero Leading Coefficients: If the coefficient of the written highest-power term cancels out to zero ($0 \cdot x^n$), it does NOT determine the degree.
  • Constant Polynomials: Any non-zero constant $c eq 0$ can be written as $c x^0$, hence has degree $0$. The zero polynomial $P(x) = 0$ has undefined degree.

Worked Anchor (NCERT Ganita Manjari §2.1)

Problem: Determine the degree of $P(x) = 3x^3 - 3x^3 + 2x + 5$.

  1. Combine like cubic terms: $3x^3 - 3x^3 = 0$.
  2. Simplified expression: $P(x) = 2x + 5 = 2x^1 + 5x^0$.
  3. Highest power with non-zero coefficient is $1$. Therefore, $ ext{deg}(P) = 1$.

Concept 2 of 6

Zeros of a Polynomial & Functional Evaluation

A real number $lpha$ is a zero (or root) of a polynomial $p(x)$ if and only if $p(lpha) = 0$.

$$p(lpha) = 0 \iff (x - lpha) ext{ is a linear factor of } p(x)$$
  • Value at a Point: Evaluating $p(k)$ involves direct functional substitution of $x = k$ into every term.
  • Geometric Core
    X-Axis Intercepts: The zeros of $p(x)$ correspond exactly to the coordinates where the graph $y = p(x)$ crosses or touches the horizontal $X$-axis ($y = 0$).
  • Linear Polynomial Zero: For $p(x) = ax + b$ with $a eq 0$, solving $ax + b = 0$ yields the unique root $lpha = -b/a$.

Worked Example

Problem: Find the zeros of $p(x) = 2x^2 - 8$.

  1. Set $p(x) = 0 \implies 2x^2 - 8 = 0$.
  2. Divide by $2$: $x^2 - 4 = 0 \implies (x - 2)(x + 2) = 0$.
  3. Roots are $x = 2$ and $x = -2$. Graph intersects $X$-axis at $(2, 0)$ and $(-2, 0)$.

Concept 3 of 6

Polynomial Remainder Theorem

Let $p(x)$ be any polynomial of degree $\ge 1$ and let $a$ be any real constant. When $p(x)$ is divided by the linear divisor $(x - a)$, the remainder is directly given by $p(a)$ without polynomial long division.

$$p(x) = (ax - b) q(x) + R \implies R = p\Big( rac{b}{a}\Big)$$
  • Division Invariant: Divisor degree is $1$, so remainder $R$ must have degree $< 1$, meaning $R$ is a constant.
  • Crux Move
    Zeroing the Quotient: Substitute the root of the divisor ($ax - b = 0 \implies x = b/a$). The quotient term $(ax - b)q(x)$ vanishes identically to zero, isolating $R = p(b/a)$.
  • Linear Invariance: Holds for any monic or non-monic linear divisor $(b - ax)$, giving remainder $p(b/a)$. (m2 Page 1 Item 2).

Worked Anchor (m2 Page 1 Item 2)

Problem: Find the remainder when $p(x) = x^4 + x^3 - 2x^2 + x + 1$ is divided by $(x - 1)$.

  1. Find the root of linear divisor: $x - 1 = 0 \implies x = 1$.
  2. Evaluate $p(1) = 1^4 + 1^3 - 2(1)^2 + 1 + 1 = 1 + 1 - 2 + 1 + 1 = 2$.
  3. By the Remainder Theorem, $R = 2$.

Arithmetic Division Pipeline

Divisor: (x - a)
Equation: p(x) = (x - a)·q(x) + R
⚡ Set x = a:
p(a) = (a - a)·q(a) + R
p(a) = 0 + R ⇒ R = p(a)
Concept 4 of 6

Factor Theorem & Monic Factorization

The Factor Theorem is the immediate zero-remainder corollary of the Remainder Theorem: $(x - a)$ is a factor of $p(x)$ if and only if $p(a) = 0$.

$$(x - a) \mid p(x) \iff p(a) = 0$$
  • Testing Potential Factors: To test if $(x - a)$ divides $p(x)$, compute $p(a)$. If $p(a) = 0$, it is a factor; if $p(a) eq 0$, it is not.
  • Crux Move
    Solving Unknown Parameter $k$: When told $(x - a)$ is a factor of a polynomial containing parameter $k$, set $p(a) = 0$ to solve for $k$.

Worked Anchor (m2 Page 2 Q25)

Problem: If $(x - a)$ is a factor of $p(x) = x^3 - a^2 x + x + 2$, find the value of $a$.

  1. By Factor Theorem, $(x - a)$ a factor $\implies p(a) = 0$.
  2. Substitute $x = a$: $a^3 - a^2(a) + a + 2 = 0$.
  3. Simplify: $a^3 - a^3 + a + 2 = 0 \implies a + 2 = 0 \implies a = -2$.

Factor Bifurcation

p(a) = 0
✓ Remainder = 0
✓ (x - a) is a factor
p(a) ≠ 0
✗ Remainder ≠ 0
✗ (x - a) is not a factor
Concept 5 of 6

Quadratic Identities & Square of Trinomial

Standard algebraic identities represent geometric surface-area decompositions of multi-variable polynomials.

$$(x + y + z)^2 = x^2 + y^2 + z^2 + 2xy + 2yz + 2zx$$
  • Square of Trinomial: The expansion contains three pure quadratic squares ($x^2 + y^2 + z^2$) plus three doubled cross-products ($2(xy + yz + zx)$).
  • Crux Symmetry
    Sign Conservation: When terms have negative signs, e.g. $(x - 2y - z)^2$, treat as $(x + (-2y) + (-z))^2$. Squares remain positive; cross-products carry product of signs.

Worked Example (m2 Checkpoint 2)

Problem: If $x + y + z = 12$ and $x^2 + y^2 + z^2 = 64$, find $xy + yz + zx$.

  1. Expand: $(x+y+z)^2 = (x^2+y^2+z^2) + 2(xy+yz+zx)$.
  2. Substitute: $12^2 = 64 + 2(xy+yz+zx) \implies 144 - 64 = 2(xy+yz+zx)$.
  3. $80 = 2(xy+yz+zx) \implies xy + yz + zx = 40$.

Special Cubic Identity & Conditional Sum Zero

The three-variable cubic identity connects the sum of cubes to the product $3abc$ under linear condition $a + b + c = 0$.

$$a^3 + b^3 + c^3 - 3abc = (a+b+c)(a^2+b^2+c^2 - ab - bc - ca)$$
$$ ext{If } a + b + c = 0 \implies a^3 + b^3 + c^3 = 3abc$$
  • Conditional Vanishing: If $a + b + c = 0$, the right-hand factor $(a + b + c)$ becomes zero, causing the entire RHS to vanish: $a^3 + b^3 + c^3 - 3abc = 0$.
  • Competitive Shortcut
    Evaluating Cube Sums: Allows calculating sums of large numerical cubes without computing single cubes, e.g., $(-12)^3 + 7^3 + 5^3$.
  • Cyclic Fractions: For expressions like $\sum rac{(a-b)^2}{(b-c)(c-a)}$, setting common denominator $(a-b)(b-c)(c-a)$ converts numerator into $(a-b)^3+(b-c)^3+(c-a)^3 = 3(a-b)(b-c)(c-a)$, giving value $3$. (m2 Page 3 Q8).

Worked Anchor (m2 Page 1 Item 5 & Page 3 Q8)

Problem: Evaluate $(-12)^3 + 7^3 + 5^3$ without cubing directly.

  1. Let $a = -12, b = 7, c = 5$.
  2. Check sum: $a + b + c = -12 + 7 + 5 = 0$.
  3. Apply identity: $a^3 + b^3 + c^3 = 3abc = 3(-12)(7)(5) = -36 imes 35 = -1260$.
