📐 Scalars vs. Vectors & Notation

A scalar quantity possesses only magnitude (e.g. mass, speed, time, temperature, work). A vector quantity possesses both magnitude and direction AND strictly obeys the vector laws of addition (e.g. displacement, velocity, acceleration, force, momentum).

Vector Notation:       \(\vec{A} = A_x\,\hat{i} + A_y\,\hat{j} + A_z\,\hat{k}\)
Magnitude:               \(|\vec{A}| = A = \sqrt{A_x^2 + A_y^2 + A_z^2}\)
Unit Vector:              \(\hat{A} = \frac{\vec{A}}{|\vec{A}|}\)   (Dimensionless, \(|\hat{A}| = 1\))
Critical Test for Vectorhood: Electric current has magnitude and direction, but it adds algebraically like a scalar (\(I = I_1 + I_2\)), violating vector addition. Hence, current is a scalar quantity, NOT a vector!

➕ Triangle & Parallelogram Laws of Addition

The resultant of two vectors \(\vec{A}\) and \(\vec{B}\) acting at an angle \(\theta\):

Resultant Magnitude:   \(R = \sqrt{A^2 + B^2 + 2AB\cos\theta}\)
Direction Angle \(\alpha\) (with vector \(\vec{A}\)):
\(\tan\alpha = \frac{B\sin\theta}{A + B\cos\theta}\)

Special Cases:
• Parallel (\(\theta = 0^\circ\)):       \(R_{\max} = A + B\)
• Anti-parallel (\(\theta = 180^\circ\)): \(R_{\min} = |A - B|\)
• Perpendicular (\(\theta = 90^\circ\)):   \(R = \sqrt{A^2 + B^2}, \quad \tan\alpha = \frac{B}{A}\)

✂️ Component Resolution in 2D & 3D

Resolving a vector into mutually perpendicular components along the coordinate axes simplifies complex multi-vector problems into independent 1D algebraic additions.

2D Resolution (Angle \(\theta\) with x-axis):
\(A_x = A\cos\theta, \quad A_y = A\sin\theta\)
\(A = \sqrt{A_x^2 + A_y^2}, \quad \tan\theta = \frac{A_y}{A_x}\)

3D Direction Cosines (Angles \(\alpha, \beta, \gamma\) with x, y, z axes):
\(\cos\alpha = \frac{A_x}{A}, \quad \cos\beta = \frac{A_y}{A}, \quad \cos\gamma = \frac{A_z}{A}\)
Fundamental Identity: \(\cos^2\alpha + \cos^2\beta + \cos^2\gamma = 1\)

✖️ Scalar (Dot) & Vector (Cross) Products

Scalar (Dot) Product:   \(\vec{A} \cdot \vec{B} = AB\cos\theta = A_x B_x + A_y B_y + A_z B_z\)
• Condition for Orthogonality: \(\vec{A} \perp \vec{B} \iff \vec{A} \cdot \vec{B} = 0\)
• Work done: \(W = \vec{F} \cdot \vec{d}\)

Vector (Cross) Product: \(\vec{A} \times \vec{B} = (AB\sin\theta)\,\hat{n}\)
• Condition for Parallelism: \(\vec{A} \parallel \vec{B} \iff \vec{A} \times \vec{B} = 0\)
• Torque: \(\vec{\tau} = \vec{r} \times \vec{F}\)
