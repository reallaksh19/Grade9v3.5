Two-dimensional kinematics and projectile model: Construction

Concept Book

Two-dimensional kinematics and projectile model

Learning promise

Independent perpendicular component motion in one frame, constant-acceleration component equations with common time, and the ideal near-Earth projectile specialization for horizontal and oblique launch questions.

Concept route

  1. Split one plane-motion event into independent x/y components with one clock
    1. Solve each axis on its own, but read both coordinates at one shared instant before calling the pair a position.
  2. Apply constant-acceleration kinematics component by component
    1. Check on each axis that its acceleration component is constant, then run the one-dimensional equations once per axis with one shared time.
  3. Select the gravity-only projectile model before using projectile consequences
    1. What makes a projectile special?
    2. Decide from what acts after release whether the gravity-only model applies, and only then put a_x = 0 and a_y = −g into the component equations.
    3. Name the requested event as a component condition before solving for its time: v_y = 0 at the apex, Δy = 0 at a return to launch height.
    4. Write the landing event from the actual drop while keeping the actual u_y, then read every requested quantity at that one event time.

Foundation route

  • Vector addition, subtraction and orientation — direct route unavailable in this product
  • One-dimensional motion — direct route unavailable in this product

Model contract

  • Use one declared non-rotating x-y frame for the whole event; both component equations use the same elapsed time.
  • When +y is chosen upward, the ideal projectile model uses a_x=0 and a_y=-g after release.

Outside this book

  • Calculus-based differentiation of a time-dependent position vector.
  • Derivation or memorization of a large catalogue of range/height/time-of-flight formulas as separate capabilities.
  • Trajectory-equation derivation as a first-slice requirement.
  • Air drag, Coriolis effects, variable gravity, target-on-incline projectile geometry and other advanced variants.

Split one plane-motion event into independent x/y components with one clock

1

Solve each axis on its own, but read both coordinates at one shared instant before calling the pair a position.

Medium concept
Section 1 of 5Next →

The key step

Perpendicular components may be solved separately because each axis equation contains only that axis's quantities, but they still describe one object at one physical time.

You need

  • Can read signed vector components in a declared x-y frame.
  • Choosing axes and keeping components signed (Physics)
  1. Choose one fixed x-y frame, one origin and one time origin for the whole plane-motion event.
    Why valid: A component value is meaningful only after its frame and sign convention are fixed.
    Result: one declared frame, origin, axis orientation and t=0
  2. Represent position, velocity and acceleration as signed x and y components in that same frame.
    Why valid: A plane vector is completely represented by its perpendicular Cartesian components once the frame is declared.
    Result: For x = 3t and y = 5t − t² at t = 1 s: (x, y) = (3, 4) m, (v_x, v_y) = (3, 3) m/s, (a_x, a_y) = (0, −2) m/s²
  3. Keep x-quantities in the x description and y-quantities in the y description while using one shared elapsed time.
    Why valid: The perpendicular component equations are independent in Cartesian kinematics, but both describe the same object during the same physical interval.
    Result: x(1) = 3 × 1 = 3 m uses only x-quantities; y(1) = 5 × 1 − 1² = 4 m uses only y-quantities; both use t = 1 s
  4. Recombine only component values that refer to the same frame and the same instant.
    Why valid: Mixing x at one time with y at another does not describe any single physical state of the object.
    Result: one physically valid plane state reconstructed from simultaneous components

Equations and validity

EquationWhat it tells youWhen you can use it
Δx=uxt+0.5axt2;Δy=uyt+0.5ayt2

Each perpendicular displacement component follows the 1D constant-acceleration displacement relation over one common interval.

  • a_x and a_y are constant over the interval.
  • Both component equations use the same elapsed time and frame.

Watch one

A drone flies in a frame with origin at its launch pad, +x east, +y up and t = 0 at launch. Its position is x(t) = 6t m and y(t) = (8t − t²) m. Find its position at t = 2 s, and decide whether the pair x(2 s), y(4 s) is a position the drone ever occupies.

  1. The frame, origin and clock are declared once for the whole flight, so both functions share one t.
  2. At t = 2 s: x(2) = 6 × 2 = 12 m and y(2) = 8 × 2 − 2² = 12 m, so the drone is at (12, 12) m.
  3. y(4) = 8 × 4 − 4² = 16 m, so the pair x(2 s), y(4 s) is (12, 16) m.
  4. x = 12 m happens only at t = 2 s, when y is 12 m rather than 16 m, so (12, 16) m is never a position of the drone.

Result

At t = 2 s the drone is at (12, 12) m. The pair (12, 16) m mixes two instants and is not a position the drone ever occupies.

Check

At t = 4 s the drone is really at (24, 16) m: substituting t = 4 into both functions gives a genuine position, and its x differs from the mixed pair's.

Solve each axis on its own, but read both coordinates at one shared instant before calling the pair a position.

A tempting wrong path

  • Independent x and y motions may use different elapsed times.
  • The x-motion and y-motion are two different objects that can be paired arbitrarily later.

Diagnose

  • At one instant 2 s after launch, may the x equation use t=2 s while the y equation uses another time?
  • May x(2 s) be combined with y(3 s) to describe the particle's position?

Repair

  • No. Independence separates the axis equations; it does not give the same object two clocks.
  • No. A plane state is a simultaneous pair. Recombine x(t) and y(t) only at the same t in the same frame.

1-2-3 quick check

  1. 1 · CheckSubstitute the reported t back into both component functions: each must return its reported coordinate. If one coordinate only matches at a different t, the pair is not a position.
  2. 2 · CheckReverse the declared +y direction: every y-quantity must change sign together while no x-quantity changes, and the physical position stays the same.

Try it with less support

A particle has x-velocity 6 m/s and y-velocity -8 m/s at t=3 s. Explain what 'independent components' means and what must remain shared between the x and y descriptions.

Apply constant-acceleration kinematics component by component

Subject: PhysicsTopic: Motion in 2 DConcept: Apply constant-acceleration kinematics component by componentConcept difficulty: Medium concept
1

Check on each axis that its acceleration component is constant, then run the one-dimensional equations once per axis with one shared time.

Medium concept
Section 2 of 5← PreviousNext →

The key step

The one-dimensional constant-acceleration equations can be applied to each perpendicular component independently when a_x and a_y are each constant over the same interval.

You need

  • Can use the existing one-dimensional constant-acceleration model.
  • Can keep x/y components separate with one common time.
  • Represent one plane-motion event as independent signed x/y component histories that share one elapsed time.
  • Derive the constant-acceleration equations from one velocity-time graph (Physics)
  1. Check separately whether a_x and a_y are constant over the interval before choosing constant-acceleration equations on either axis.
    Why valid: The familiar one-dimensional kinematic relations are exact only on an axis whose acceleration component is constant over the interval.
    Result: per-axis model-validity decision
  2. Apply the one-dimensional constant-acceleration relations independently to x and y using only that axis's signed values and the same t.
    Why valid: Each Cartesian component obeys the same one-dimensional relation when its acceleration component is constant.
    Result: v_x=u_x+a_x t; v_y=u_y+a_y t; Delta x=u_x t+0.5a_x t^2; Delta y=u_y t+0.5a_y t^2
  3. If one axis determines an event time, reuse that same time on the other axis before recombining and checking the plane state.
    Why valid: The event occurs once for the object; a time obtained from one component is the clock value for every component at that same event.
    Result: event time transferred across axes, then one checked plane state

Equations and validity

EquationWhat it tells youWhen you can use it
vx=ux+axt;vy=uy+ayt

Each perpendicular velocity component follows the 1D constant-acceleration relation over one common interval.

  • a_x and a_y are constant over the interval.
  • Both component equations use the same elapsed time and frame.
Δx=uxt+0.5axt2;Δy=uyt+0.5ayt2

Each perpendicular displacement component follows the 1D constant-acceleration displacement relation over one common interval.

  • a_x and a_y are constant over the interval.
  • Both component equations use the same elapsed time and frame.

Watch one

A puck on a tilted air table starts at the origin with velocity (4 i + 6 j) m/s, and its acceleration is (0 i − 2 j) m/s² throughout. Using the table's x-y frame, decide which constant-acceleration equations apply on each axis, find when the puck is next at y = 0, and find its x-position and velocity at that instant.

  1. a_x = 0 and a_y = −2 m/s² are both constant, so the constant-acceleration relations are exact on both axes.
  2. On y: Δy = 6t − 0.5 × 2 × t² = 6t − t². Setting Δy = 0 gives t(6 − t) = 0, and the later root is t = 6 s.
  3. On x, at the same t = 6 s: Δx = 4 × 6 = 24 m.
  4. Velocity at t = 6 s: v_x = 4 m/s and v_y = 6 − 2 × 6 = −6 m/s, so v = (4 i − 6 j) m/s.

Result

The puck is next at y = 0 at t = 6 s, at x = 24 m, moving with v = (4 i − 6 j) m/s.

Check

v_y comes back with its starting size, 6 m/s, and the opposite sign, as v_y² = u_y² + 2a_y Δy requires when Δy = 0; v_x is unchanged because a_x = 0.

Check on each axis that its acceleration component is constant, then run the one-dimensional equations once per axis with one shared time.

A tempting wrong path

  • The magnitude of acceleration should be inserted unchanged into both x and y equations.
  • If one acceleration component is constant, the constant-acceleration equations are automatically valid on both axes.
  • A time found from the x equation may be replaced by a different convenient time in the y equation.

Diagnose

  • If a=(10 i + 4 j) m/s², should both component equations use a=√116?
  • If a_x is constant but a_y changes with time, may the same constant-acceleration displacement formula be used exactly on y over the whole interval?
  • If x-motion says an event occurs at t=3 s, what time belongs in the y equation for that same event?

Repair

  • No. Use a_x=10 only in the x equation and a_y=4 only in the y equation; the magnitude is not either component.
  • No. Model validity is checked per axis. A constant a_x does not make a_y constant.
  • Use t=3 s. Both components describe the same event and therefore share one clock.

1-2-3 quick check

  1. 1 · CheckEvery term of Δy = u_y t + 0.5 a_y t² must come out in metres: (m/s)(s) and (m/s²)(s²). A velocity term in m/s beside them means a t is missing.
  2. 2 · CheckSet a_x = 0: the x equations must reduce to uniform motion, v_x = u_x and Δx = u_x t, whatever happens on y.

Try it with less support

A particle starts with u=(0,5) m/s and constant a=(10,4) m/s². Set up the x and y position equations at common time t without solving a particular numerical t.

What makes a projectile special?

D1 Foundation
Foundational OpenerNext →

Start with the idea

  • After launch, an ideal projectile keeps moving while gravity continually pulls downward.
  • Its curved path is called the trajectory.

Physics Words

  • Projectile: An object thrown or projected into the air, subject only to gravity in the ideal model.
  • Trajectory: The curved flight path followed by a projectile under gravity.
  • Launch Velocity: The initial velocity vector at the instant of release.

Model Check

  • Near-Earth motion where gravitational acceleration g is assumed constant in magnitude and direction.
  • Air resistance is neglected in the ideal model.
  • After launch, gravity is the only continuing force considered by the model.

Easy mistake to make

Thinking a forward force must keep pushing the projectile. In the ideal model, the continuing acceleration is downward due to gravity; forward motion continues by inertia.

1

Decide from what acts after release whether the gravity-only model applies, and only then put a_x = 0 and a_y = −g into the component equations.

Medium concept
Section 3 of 5← PreviousNext →

The key step

After release in the ideal near-Earth model, projectile motion is not a new set of laws: it is the same component kinematics with a_x=0 and a_y=-g (for +y upward).

You need

  • Can solve 2D constant-acceleration component equations.
  • If an oblique launch angle is given, angle-based vector decomposition is available as a separate prerequisite for that question.
  • Apply constant-acceleration kinematics independently to x and y components of one plane-motion event.
  1. Decide whether the object is in ideal near-Earth free flight after release; neglect air resistance, declare +y, then set a_x=0 and a_y=-g.
    Why valid: The standard projectile equations are a conditional specialization of 2D constant acceleration, not an automatic label for every launched object.
    Result: gravity-only projectile acceleration state
  2. Use supplied or separately resolved u_x and u_y with one common t in the horizontal and vertical component equations.
    Why valid: Horizontal, oblique and downward/upward initial components change the initial state, not the gravity-only model.
    Result: v_x=u_x; v_y=u_y-g t; Delta x=u_x t; Delta y=u_y t-0.5g t^2

Equations and validity

EquationWhat it tells youWhen you can use it
ax=0;ay=−g;vx=ux;vy=uy−gt;Δx=uxt;Δy=uyt−0.5gt2

With +y upward, air resistance neglected and near-Earth constant g, projectile motion is 2D constant acceleration specialized to zero horizontal and downward vertical acceleration.

  • Near-Earth region with approximately constant g.
  • Air resistance neglected.
  • +y is declared upward for the displayed signs.
  • The object is in free flight after release.

Watch one

A ball is thrown from a balcony with u_x = 8 m/s and u_y = 6 m/s. After release only gravity acts, and air resistance is negligible. Take +y upward and g = 10 m/s². Decide whether the ideal projectile model applies, write its component relations, and find the ball's displacement and velocity 1 s after release.

  1. After release the only retained interaction is gravity, so the ideal model applies: a_x = 0 and a_y = −10 m/s².
  2. Component relations: v_x = 8, v_y = 6 − 10t, Δx = 8t and Δy = 6t − 5t², in metres and seconds.
  3. At t = 1 s: Δx = 8 m and Δy = 6 − 5 = 1 m, so the displacement is (8 i + 1 j) m.
  4. At t = 1 s: v_x = 8 m/s and v_y = 6 − 10 = −4 m/s, so v = (8 i − 4 j) m/s.

Result

The model applies with a = (0, −10) m/s². After 1 s the displacement is (8 i + 1 j) m and the velocity is (8 i − 4 j) m/s.

Check

v_y is negative at 1 s, so the ball is already falling; its apex was at t = 6/10 = 0.6 s. Its speed squared, 8² + 4² = 80, equals u² − 2gΔy = 100 − 20.

Decide from what acts after release whether the gravity-only model applies, and only then put a_x = 0 and a_y = −g into the component equations.

A tempting wrong path

  • A projectile needs a horizontal force to keep moving horizontally.
  • A horizontal launch has no vertical velocity throughout the flight.

Diagnose

  • If a_x=0 after release, can v_x still be nonzero?
  • One second after a horizontal launch, is v_y still zero under gravity?

Repair

  • Yes. Zero horizontal acceleration means horizontal velocity stays constant, not that it becomes zero.
  • No. u_y=0 only at release; a_y=-g makes v_y=-gt afterward.

1-2-3 quick check

  1. 1 · CheckSet g = 0: the equations must reduce to straight-line uniform motion with the launch velocity (u_x, u_y).
  2. 2 · CheckWith +y up, v_y must fall by g every second whatever the launch direction; a v_y that grows while the object rises means the sign of g is wrong.

Name the requested event as a component condition before solving for its time: v_y = 0 at the apex, Δy = 0 at a return to launch height.

Medium concept
Section 4 of 5← PreviousNext →
  1. Translate the requested event into the component condition that defines it before solving for time.
    Why valid: Apex, same-height return, ground impact and a specified later instant are different events; each is identified by a different component condition.
    Result: event condition chosen before calculation
  2. For an apex event, set v_y=0 while keeping v_x=u_x and a_y=-g.
    Why valid: At the highest point only the vertical velocity component is momentarily zero; gravity still accelerates downward and horizontal motion continues.
    Result: apex condition v_y=0 with nonzero horizontal velocity and nonzero downward acceleration
  3. For a return to the launch height, set Delta y=0 and treat any same-height flight-time/range shortcut as conditional on that equality.
    Why valid: The shortcut follows from the vertical displacement returning to its initial value; it is not valid when the landing height differs.
    Result: same-height event condition and its validity boundary

Watch one

An ideal projectile is launched from level ground with u_x = 6 m/s and u_y = 15 m/s. Take +y upward and g = 10 m/s². Name the component condition for each event, then find the time and height of the apex, and the time and range when it lands back at launch height.

  1. Apex: the condition is v_y = 0, while v_x stays 6 m/s and a_y stays −10 m/s². 15 − 10t = 0 gives t = 1.5 s.
  2. Apex height: Δy = 15 × 1.5 − 5 × 1.5² = 22.5 − 11.25 = 11.25 m.
  3. Landing at launch height: the condition is Δy = 0. 15t − 5t² = 0 gives t = 0 (the launch) or t = 3 s, so the landing is at t = 3 s.
  4. Range at the same t = 3 s: Δx = 6 × 3 = 18 m.

Result

Apex at t = 1.5 s, 11.25 m above launch, with velocity (6 i + 0 j) m/s; landing at t = 3 s, 18 m from launch.

Check

The landing time is twice the apex time, 3 s = 2 × 1.5 s, and the apex height agrees with u_y²/(2g) = 225/20 = 11.25 m, found without any time.

Name the requested event as a component condition before solving for its time: v_y = 0 at the apex, Δy = 0 at a return to launch height.

A tempting wrong path

  • At the highest point the whole velocity and the acceleration are both zero.
  • At two points of the same height on an ideal trajectory, the velocity vectors are identical.

Diagnose

  • At the apex of an oblique projectile, which of v_x, v_y and a_y is zero?
  • On ascent and descent at the same height, how do the horizontal and vertical velocity components compare?

Repair

  • Only v_y is zero at that instant. v_x remains u_x and a_y remains -g.
  • v_x is the same, while v_y has equal magnitude and opposite sign; the speed matches but the velocity vector does not.

1-2-3 quick check

  1. 1 · CheckFor a return to launch height the flight time must be exactly twice the apex time, 2u_y/g against u_y/g, because the rise and the fall mirror each other.
  2. 2 · CheckSet u_y = 0 in the apex condition: the apex must fall at t = 0, as it does for a launch that starts level.
3

Write the landing event from the actual drop while keeping the actual u_y, then read every requested quantity at that one event time.

Medium concept
Section 5 of 5← Previous
  1. For any unequal-height landing, use the actual Delta y=y_f-y_i in the vertical position equation and retain the actual u_y; for a horizontal launch specifically, set u_y=0, then obtain the event time vertically and share it with x.
    Why valid: Initial vertical velocity and landing displacement describe different facts. The landing event is fixed by the actual vertical geometry, while u_y=0 is only the horizontal-launch initial condition.
    Result: Delta y=y_f-y_i=u_y t_event-0.5g t_event^2; for horizontal launch u_y=0; reuse the solved t_event on x
  2. At the selected event time, reconstruct the requested velocity, speed, direction, displacement or range from simultaneous components and check qualitative limits.
    Why valid: The reported projectile result is a consequence of one component model and one event, so its components must refer to the same instant and satisfy a_x=0, a_y=-g.
    Result: checked projectile consequence at one physical event

Watch one

A ball is thrown from the edge of a roof 25 m above level ground with u_x = 5 m/s and u_y = 20 m/s. Take +y upward and g = 10 m/s², and neglect air resistance. Find when it hits the ground, how far from the building it lands, and its impact velocity and speed.

  1. The landing event is Δy = −25 m, because the ground is below the launch point, and u_y = 20 m/s is kept: −25 = 20t − 5t².
  2. Rearranged, 5t² − 20t − 25 = 0, so t² − 4t − 5 = 0 and (t − 5)(t + 1) = 0. The physical root is t = 5 s.
  3. Reuse t = 5 s horizontally: Δx = 5 × 5 = 25 m.
  4. At t = 5 s: v_x = 5 m/s and v_y = 20 − 10 × 5 = −30 m/s, so v = (5 i − 30 j) m/s and the speed is √(5² + 30²) = √925 ≈ 30.4 m/s.

Result

Impact at t = 5 s, 25 m from the building, with v = (5 i − 30 j) m/s and a speed of about 30.4 m/s.

Check

Without time: v² = u² + 2gh = (5² + 20²) + 2 × 10 × 25 = 425 + 500 = 925 m²/s², the same speed squared as from the components.

Write the landing event from the actual drop while keeping the actual u_y, then read every requested quantity at that one event time.

A tempting wrong path

  • A horizontal launch has no vertical velocity throughout the flight.
  • Same-height flight formulas may be used whenever the question is about a projectile range or flight time.
  • Horizontal speed determines how long a horizontally launched object takes to fall.

Diagnose

  • One second after a horizontal launch, is v_y still zero under gravity?
  • A ball launched from a roof lands on the ground below. May the same-height time-of-flight shortcut be used without checking the vertical displacement?
  • If the horizontal launch speed doubles from the same height, does the ideal fall time change?

Repair

  • No. u_y=0 only at release; a_y=-g makes v_y=-gt afterward.
  • No. Same-height shortcuts require Delta y=0 between launch and landing. For unequal heights, solve the vertical position condition.
  • No. The vertical position equation determines the fall time; horizontal speed changes the range, not the fall time.

1-2-3 quick check

  1. 1 · CheckThe impact speed from the components must match v² = u² + 2gh for a drop h, a route that uses no time at all.
  2. 2 · CheckLet the drop shrink to zero: the landing time must reduce to the same-height value 2u_y/g.

Try it with less support

A stone is launched horizontally from a cliff with speed u. With +y upward and air resistance neglected, write its component acceleration, velocity and displacement relations after release and explain why one common t is used.
