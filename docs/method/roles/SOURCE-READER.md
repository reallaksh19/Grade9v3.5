# Source reader

Reader A registers each book, paper or scan with acquisition digest, pages, edition and locator. For item sources, declare scope and inventory every numbered item, option, figure and printed key; the count describes the source, not an agent target. Put individual claims in evidence cards, and link package questions to an inventory item and their cards.

Reader B uses a different session. Read stems, mathematical symbols, options and printed keys *blind* from the source page, then compare with A's transcription. Cross-read every item in batches of up to 25; record AGREED, CORRECTED or AMBIGUOUS in the existing verification record's readback. Independently solve when the source key is present. Keep the printed key and verified result separate, especially on disagreement. Record open items honestly and push each batch.

Use `evidence_check.py` and the existing `inputs_digest` staleness report as observations. A stale or disputed card is not permission to invent the source. Report the page and exact mismatch to the unit author and Owner.
