# Core1-family conceptual progression integrity

Issue: #256  
Programme: #252  
Stack base: Phase‑3 draft PR #262

## Governing progression

```text
Core1
compact semantic orientation / map
        ↓
Core1A
completed construction of microtopic.inferential_jump
        ↓
Core1B
learner reconstruction of that same inferential jump
```

The canonical concept is not copied between products. `microtopic.inferential_jump`
and `microtopic.intrinsic_badge` remain the single academic authorities.

## Cross-Core findings are not local debt

Phase 4 deliberately separates two classes of evidence.

**Local phase debt** stays owned by the phase that discovered it:

- Phase 1 orientation debt: e.g. a declared primary representation lacks a Core1 scene;
- Phase 2 construction debt: e.g. a representation bridge or worked conceptual anchor is missing;
- Phase 3 reconstruction debt: e.g. incomplete elicitation or A/B route asymmetry.

**Cross-progression debt** is narrower:

- a routed A/B concept has no Core1 map;
- Core1A and Core1B route different conceptual coverage;
- a canonical concept is silently unrouted;
- a teaching route references no canonical microtopic;
- a MEDIUM/HARD concept disappears from Core1 hard-transition orientation;
- the canonical inferential jump itself is absent.

This separation prevents the 89 Phase‑2 migration items from being incorrectly
relabelled as 89 cross-product failures.

## Core1 relationless-map correction

Before Phase 4, Core1 compiler support was equivalent to:

`bucket has at least one governing relation`.

That was too narrow. Seven Physics buckets already had complete Core1A/Core1B study
coverage but were denied Core1 solely because no microtopic bound an equation.

Core1 is a semantic map, so a bucket is now orientable when the canonical library can
emit at least one legitimate map surface:

- governing relations;
- declared conventions;
- declared scope;
- MEDIUM/HARD transition pointers;
- a declared primary representation with a Core1 scene.

No prose is invented to make a bucket renderable.

After this correction all **21/21** current buckets have canonical Core1 orientation
surfaces. The seven previously relationless buckets are carried primarily by their
hard-transition pointers; the gravitation bucket also carries declared scope.

## Reviewer obligations

Mechanical coherence does not prove pedagogical quality. Review still decides whether:

- Core1 remains a map rather than compressed teaching;
- Core1A genuinely constructs the inferential jump;
- Core1B genuinely makes the learner perform that construction;
- canonical representation meaning remains stable across products.

No text-similarity score, page quota or keyword heuristic is used as a substitute.

## Forward gate

Guardrails regenerates the report and rejects any new cross-progression finding relative
to the committed baseline. Existing local Phase‑1/2/3 debt continues to be governed by
its own phase gates.

## Handoff to Phase 5

Phase 5 must prove that this progression survives learner delivery:

- Core1 orientation renders as Core1;
- Core1A exposes the complete construction;
- Core1B remains attempt-first and reconstructive;
- shared canonical representation meaning survives projection/runtime;
- completion does not become mastery/readiness evidence.
