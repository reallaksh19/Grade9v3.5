# AP-005 — Answers in hidden live DOM

**Observed:** [review commit `1a047ec0`](https://github.com/reallaksh19/Grade9V3/commit/1a047ec0), RCA-UX-005; COV-05. This card paraphrases the observed mechanism; its before/after sketches are teaching examples, not quotations from the review.

**Learner experience:** Search or accessibility exposes a result that is visually collapsed.

**Mechanism:** A disclosure or hidden node contains answer bytes before commitment.

**Before, pattern sketch:** Answer text is in a closed live details element.

**After, repair sketch:** Answer bytes are in a template and materialise after typed commitment.

**Technique:** T01, T03 in [TECHNIQUES.md](../TECHNIQUES.md).

**Structurally impossible now?** Yes under SPEC-AM2 WP3 inert-template rendering.
