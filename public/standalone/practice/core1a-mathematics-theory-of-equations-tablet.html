🔗 The Fundamental Triad: Roots ↔ Factors ↔ Coefficients

By the Factor Theorem, if $x = \alpha$ is a root of polynomial equation $P(x) = 0$, then $(x - \alpha)$ is an exact linear factor of $P(x)$.

Monic Polynomial of Degree n with roots α₁, α₂, ..., αₙ:
P(x) = (x - α₁) (x - α₂) ··· (x - αₙ) = 0

Expanding this product yields the polynomial in standard form:
P(x) = xⁿ - S₁ xⁿ⁻¹ + S₂ xⁿ⁻² - S₃ xⁿ⁻³ + ··· + (-1)ⁿ Sₙ = 0
where Sₖ is the k-th elementary symmetric sum of the roots.

⚖️ Vieta's Formulas for Cubic and Quartic Equations

For a general cubic equation $a x^3 + b x^2 + c x + d = 0$ ($a eq 0$) with roots $\alpha, \beta, \gamma$:

Sum of roots taken 1 at a time (S₁):
  α + β + γ = - b / a

Sum of products taken 2 at a time (S₂):
  αβ + βγ + γα = c / a

Product of all 3 roots (S₃):
  α · β · γ = - d / a

Quartic Equation ($a x^4 + b x^3 + c x^2 + d x + e = 0$)

S₁ = ∑ α = - b / a
S₂ = ∑ αβ = c / a
S₃ = ∑ αβγ = - d / a
S₄ = αβγδ = e / a

🏗️ Constructing Equations from Roots

To construct a polynomial equation whose roots are given:

Given roots: r₁, r₂, r₃
Step 1: Compute S₁ = r₁ + r₂ + r₃
Step 2: Compute S₂ = r₁ r₂ + r₂ r₃ + r₃ r₁
Step 3: Compute S₃ = r₁ r₂ r₃
Step 4: Equation is x³ - S₁ x² + S₂ x - S₃ = 0 (multiply through to clear fractions).

✨ Symmetric Functions of Roots

A function $f(\alpha, \beta, \gamma)$ is symmetric if exchanging any two roots leaves the function completely unchanged.

Common Symmetric Expansions:
• α² + β² + γ² = (α + β + γ)² - 2 (αβ + βγ + γα) = S₁² - 2 S₂
• 1/α + 1/β + 1/γ = (αβ + βγ + γα) / (αβγ) = S₂ / S₃
• α³ + β³ + γ³ = S₁³ - 3 S₁ S₂ + 3 S₃
