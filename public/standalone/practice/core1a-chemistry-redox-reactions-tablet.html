MOD-RED-01

Oxidation Number — Definition & Priority Rules

Core 1 · Pages 3–4
🎯 Learning Target: Assign oxidation numbers systematically using strict hierarchy and total charge sum rule.
🧠 Memory Anchor
Elemental state = 0. Group 1 = +1, Group 2 = +2, F = -1, H = +1 (hydrides -1), O = -2 (peroxides -1, OF₂ +2). Sum equals net charge.
⚙️ Why It Works
Oxidation numbers are formal bookkeeping tools tracking electron control assuming 100% ionic character. When electronegative bonds break heterolytically, shared pairs are credited to the more electronegative atom.
🔍 Worked Contrast
Flawed: Assuming Cr in CrO₅ is +10 from formula x - 10 = 0. Correct: Butterfly structure has 4 peroxo oxygens (-1) and 1 oxo oxygen (-2), yielding Cr = +6 (maximum possible).

✍️ Active Practice & Step-by-Step Working

Problem: Determine the oxidation state of S in Caro's acid (H₂SO₅) and Cr in CrO₅.

Reveal Checked Model Answer
H₂SO₅: Structure contains one peroxo bond (-O-O-). Two peroxo oxygens are -1, three oxo oxygens are -2. 2(+1) + S + 3(-2) + 2(-1) = 0 => S = +6. CrO₅: Cr = +6.
⚠️ Common Trap to Avoid
Do not exceed maximum oxidation state (group valence). If calculation yields Cr > +6 or S > +6, suspect peroxide linkage (-O-O-).

MOD-RED-02

Oxidation & Reduction — Dual Language Equivalence

Core 1 · Page 5
🎯 Learning Target: Map classical oxygen/hydrogen transfer onto modern electron transfer and oxidation-number shifts.
🧠 Memory Anchor
OIL RIG: Oxidation Is Loss of electrons (ON increases). Reduction Is Gain of electrons (ON decreases).
⚙️ Why It Works
Every redox reaction is an electron exchange. The increase in oxidation state of one species must exactly equal the decrease in oxidation state of the other species.
🔍 Worked Contrast
Flawed: Thinking oxidation always requires oxygen. Correct: 2Na + Cl₂ → 2NaCl is oxidation of Na (0 → +1) without oxygen present.
✍️ Active Practice & Step-by-Step Working

Problem: In the reaction H₂S + Cl₂ → 2HCl + S, identify what is oxidised and what is reduced.

Reveal Checked Model Answer
S in H₂S goes from -2 to 0 (ON increases → H₂S is oxidised). Cl in Cl₂ goes from 0 to -1 (ON decreases → Cl₂ is reduced).
⚠️ Common Trap to Avoid
Forgetting that negative to less negative (e.g. -2 to 0) is an INCREASE in oxidation number (oxidation).

MOD-RED-03

Oxidising & Reducing Agents — The Naming Inversion

Core 1 · Page 6
🎯 Learning Target: Identify oxidants and reductants without confusing the agent with the process it undergoes.
🧠 Memory Anchor
THE INVERSION: The Oxidising Agent gets reduced (accepts e⁻). The Reducing Agent gets oxidised (donates e⁻).
⚙️ Why It Works
An agent causes change in something else. An oxidising agent oxidises its partner by stripping electrons from it, thereby absorbing those electrons and getting reduced.
🔍 Worked Contrast
Flawed: Calling Zn the oxidising agent because it undergoes oxidation. Correct: Zn causes reduction of H⁺; therefore Zn is the reducing agent.
✍️ Active Practice & Step-by-Step Working

Problem: In CuO + H₂ → Cu + H₂O, name the oxidising agent and the reducing agent with physical reasoning.

Reveal Checked Model Answer
CuO is reduced (Cu: +2 → 0) => CuO is the Oxidising Agent. H₂ is oxidised (H: 0 → +1) => H₂ is the Reducing Agent.
⚠️ Common Trap to Avoid
Do not identify single atoms as agents; name the entire reactant molecule/formula unit as the agent.

MOD-RED-04

Redox vs Non-Redox — Verification from Oxidation Numbers

Core 1 · Page 7
🎯 Learning Target: Differentiate true redox reactions from acid-base neutralisations and precipitation reactions.
🧠 Memory Anchor
Redox criterion: At least one atom must increase in ON AND at least one atom must decrease in ON.
⚙️ Why It Works
Many vivid chemical reactions involve precipitate formation or colour change without any electron transfer. Only changes in oxidation numbers prove redox character.
🔍 Worked Contrast
Flawed: Classifying NaOH + HCl → NaCl + H₂O as redox because bonds broke. Correct: Na(+1), O(-2), H(+1), Cl(-1) throughout; zero ON change => Non-Redox.
✍️ Active Practice & Step-by-Step Working

Problem: Classify as redox or non-redox: (a) AgNO₃ + NaCl → AgCl + NaNO₃, (b) 2KClO₃ → 2KCl + 3O₂.

Reveal Checked Model Answer
(a) Non-redox: Ag(+1), N(+5), O(-2), Na(+1), Cl(-1) unchanged. (b) Redox: Cl(+5 → -1, reduced), O(-2 → 0, oxidised).
⚠️ Common Trap to Avoid
Assuming all decomposition reactions are redox. CaCO₃ → CaO + CO₂ is non-redox (Ca=+2, C=+4, O=-2 unchanged!).

MOD-RED-05

Reaction Types: Displacement, Disproportionation & Comproportionation

Core 1 · Pages 8–9
🎯 Learning Target: Classify redox topologies: combination, decomposition, displacement, and disproportionation.
🧠 Memory Anchor
Disproportionation: SAME element in an intermediate oxidation state simultaneously oxidises and reduces.
⚙️ Why It Works
For an element to disproportionate, it must possess at least 3 available oxidation states (one higher, one lower). Elements in their highest oxidation state (e.g. Cl in ClO₄⁻) cannot disproportionate.
🔍 Worked Contrast
Flawed: Claiming 2H₂O₂ → 2H₂O + O₂ has two different elements reacting. Correct: Oxygen in H₂O₂ (-1) splits into O in H₂O (-2, reduced) and O in O₂ (0, oxidised).
✍️ Active Practice & Step-by-Step Working

Problem: Why can Cl₂ disproportionate in alkaline medium to Cl⁻ and ClO⁻, but F₂ cannot?

Reveal Checked Model Answer
Cl has oxidation states -1, 0, +1, +3, +5, +7, so 0 can split to -1 and +1. Fluorine is the most electronegative element with only 0 and -1 oxidation states; it cannot exhibit positive oxidation states.
⚠️ Common Trap to Avoid
Confusing disproportionation with intermolecular redox. In disproportionation, a single species acts as both oxidant and reductant.

MOD-RED-06

Half-Reaction Balancing — Acidic & Basic Medium

Core 1 · Pages 10–11
🎯 Learning Target: Balance complex redox equations using the Ion-Electron method with exact mass and charge conservation.
🧠 Memory Anchor
Acidic: Balance atoms ≠ H, O → Balance O with H₂O → Balance H with H⁺ → Balance charge with e⁻. Basic: Add OH⁻ equal to H⁺ to both sides to form H₂O.
⚙️ Why It Works
Electrons cannot exist free in solution; total electrons lost in oxidation must strictly equal total electrons gained in reduction.
🔍 Worked Contrast
Flawed: Balancing atoms but leaving unequal charges on product and reactant sides. Correct: Mass balance AND charge balance must both match.
✍️ Active Practice & Step-by-Step Working

Problem: Balance in acidic medium: MnO₄⁻ + Fe²⁺ → Mn²⁺ + Fe³⁺.

Reveal Checked Model Answer
Oxidation: 5(Fe²⁺ → Fe³⁺ + e⁻). Reduction: MnO₄⁻ + 8H⁺ + 5e⁻ → Mn²⁺ + 4H₂O. Overall: MnO₄⁻ + 5Fe²⁺ + 8H⁺ → Mn²⁺ + 5Fe³⁺ + 4H₂O.
⚠️ Common Trap to Avoid
Forgetting to multiply half-reactions by integers before summing so that electrons cancel out completely.

MOD-RED-07

Equivalent Mass & n-Factor in Redox

Core 1 · Pages 12–13
🎯 Learning Target: Calculate reaction-dependent n-factor and equivalent mass for oxidants, reductants, and titrations.
🧠 Memory Anchor
n-factor for Redox = Total change in oxidation number PER MOLE of the specified formula unit. Equivalent Mass = Molar Mass / n.
⚙️ Why It Works
Unlike acid-base acidity/basicity, redox n-factor is not fixed by formula; it depends strictly on the reaction medium and product formed.
🔍 Worked Contrast
KMnO₄ in acidic medium: Mn(+7) → Mn²⁺(Δ=5, n=5). In neutral/faintly alkaline: Mn(+7) → MnO₂(Δ=3, n=3). In strongly alkaline: Mn(+7) → MnO₄²⁻(Δ=1, n=1).

✍️ Active Practice & Step-by-Step Working

Problem: Find the n-factor of Cr₂O₇²⁻ when it reduces to Cr³⁺ in acidic medium.

Reveal Checked Model Answer
Cr₂O₇²⁻ has 2 Cr atoms. Each Cr goes from +6 to +3 (change = 3). Total change per formula unit = 2 × 3 = 6. Therefore n-factor = 6, Equivalent weight = M/6.
⚠️ Common Trap to Avoid
Multiplying the change in oxidation state by the coefficient in the balanced equation instead of the subscript in the reactant formula unit.

Q1 · NCERT Unit 2 Q2

Rusting: Corrosion & Chemical Change

Core 2 NCERT Helper

Rusting of an article made of iron is called what, and is it a physical or chemical change?

💡 See the Idea (Visual First Move)
Rusting converts metallic iron into hydrated iron(III) oxide (Fe₂O₃·xH₂O). New chemical bonds form and electrons are transferred.
👨‍🏫 Teacher-Style Helper
Physical changes alter appearance or state without changing composition. Rusting forms a completely new chemical compound with distinct properties.
✍️ Your Working & Answer Commit
Reveal Answer & 5-Step Solution
Immediate Answer: Rusting is called Corrosion, and it is a Chemical Change.

Complete Solution:
1. Understand: Identify the process transforming shiny iron metal into reddish-brown flaky material. 2. Chemistry: Fe(s) is oxidised by O₂(g) in the presence of H₂O to form hydrated ferric oxide Fe₂O₃·xH₂O. 3. Electron transfer: Fe(0) → Fe³⁺ + 3e⁻ (oxidation). O₂(0) + 4e⁻ → 2O²⁻ (reduction). 4. Conclusion: A new substance with distinct chemical identity is formed irreversibly, satisfying the definition of a chemical change.

Q2 · NCERT Unit 2 Q6

Distinguishing Physical from Chemical Changes

Core 2 NCERT Helper

Which of the following are physical changes? (a) Melting of iron, (b) Rusting of iron, (c) Bending of an iron rod, (d) Drawing a wire of iron metal.

💡 See the Idea (Visual First Move)
State changes (melting) and shape changes (bending, drawing) preserve elemental Fe bonds; only rusting alters chemical composition.
👨‍🏫 Teacher-Style Helper
Ask: Can the original material be restored by simple physical reversal without a chemical reaction?
✍️ Your Working & Answer Commit
Reveal Answer & 5-Step Solution
Immediate Answer: (a) Melting of iron, (c) Bending of an iron rod, and (d) Drawing a wire are physical changes.

Complete Solution:
1. Melting (a) is a phase transition solid → liquid, preserving atomic iron. 2. Bending (c) and drawing (d) are mechanical deformations affecting lattice geometry without altering chemical composition. 3. Rusting (b) forms iron oxide, which is a chemical reaction.

Q3 · NCERT Unit 2 Q15(c)

Heating Iron and Sulphur

Core 2 NCERT Helper

When a mixture of iron filings and sulphur powder is heated strongly, a black compound FeS is formed. Is this a physical or chemical change? Identify oxidation states.

💡 See the Idea (Visual First Move)
Elemental Fe (0) and S (0) react exothermically to form iron(II) sulphide (Fe²⁺S²⁻).
👨‍🏫 Teacher-Style Helper
Notice the change in magnetic properties: iron in FeS is no longer attracted to a magnet because it is chemically bonded.
✍️ Your Working & Answer Commit
Reveal Answer & 5-Step Solution
Immediate Answer: Chemical change (Redox combination). Fe is oxidised (0 to +2), S is reduced (0 to -2).

Complete Solution:
1. Reaction: Fe(s) + S(s) → FeS(s). 2. Oxidation states: Fe goes from 0 to +2 (loss of 2e⁻, oxidation). S goes from 0 to -2 (gain of 2e⁻, reduction). 3. Fe acts as reducing agent; S acts as oxidising agent.

Q4 · NCERT Unit 2 Q18(b)

Zinc + Hydrochloric Acid

Core 2 NCERT Helper

Zinc granules react with dilute hydrochloric acid to produce hydrogen gas and zinc chloride. Identify: (a) what is oxidised, (b) what is reduced, (c) the oxidising agent.

💡 See the Idea (Visual First Move)
Displacement of hydrogen by a more electropositive metal: Zn + 2HCl → ZnCl₂ + H₂.
👨‍🏫 Teacher-Style Helper
Write net ionic equation: Zn(s) + 2H⁺(aq) → Zn²⁺(aq) + H₂(g). Chloride is a spectator ion.
✍️ Your Working & Answer Commit
Reveal Answer & 5-Step Solution
Immediate Answer: (a) Zn is oxidised, (b) H⁺ is reduced, (c) HCl (or H⁺) is the oxidising agent.

Complete Solution:
1. Ionic form: Zn⁰ + 2H⁺ + 2Cl⁻ → Zn²⁺ + H₂⁰ + 2Cl⁻. 2. Zn: 0 to +2 (oxidised; reducing agent). 3. H⁺: +1 to 0 (reduced; oxidising agent). 4. Cl⁻: -1 on both sides (spectator ion).

Q5 · NCERT Unit 2 Q29

Chemical but Non-Redox: Double Displacement

Core 2 NCERT Helper

Barium chloride solution is mixed with sodium sulphate solution. A white precipitate forms. Write the reaction, state if it is redox, and explain.

💡 See the Idea (Visual First Move)
BaCl₂(aq) + Na₂SO₄(aq) → BaSO₄(s) + 2NaCl(aq).
👨‍🏫 Teacher-Style Helper
Track the oxidation number of each element before and after precipitation.
✍️ Your Working & Answer Commit
Reveal Answer & 5-Step Solution
Immediate Answer: BaCl₂ + Na₂SO₄ → BaSO₄↓ + 2NaCl. It is a NON-REDOX double displacement reaction.

Complete Solution:
1. Reactants: Ba = +2, Cl = -1, Na = +1, S = +6, O = -2. 2. Products: Ba = +2, S = +6, O = -2 (in BaSO₄); Na = +1, Cl = -1 (in NaCl). 3. No atom changes oxidation state. It is an ionic precipitation (exchange of partner ions), hence non-redox.
