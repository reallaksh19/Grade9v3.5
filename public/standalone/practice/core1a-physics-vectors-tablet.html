📐 Scalars vs. Vectors & Notation

A scalar quantity possesses only magnitude (e.g. mass, speed, time, temperature, work). A vector quantity possesses both magnitude and direction AND strictly obeys the vector laws of addition (e.g. displacement, velocity, acceleration, force, momentum).

Vector Notation:   A⃗ = A_x î + A_y ĵ + A_z k̂
Magnitude:         |A⃗| = A = √(A_x² + A_y² + A_z²)
Unit Vector:       Â = A⃗ / |A⃗|   (Dimensionless, |Â| = 1)
Critical Test for Vectorhood: Electric current has magnitude and direction, but it adds algebraically like a scalar ($I = I_1 + I_2$), violating vector addition. Hence, current is a scalar quantity, NOT a vector!

➕ Triangle & Parallelogram Laws of Addition

The resultant of two vectors $ ec{A}$ and $ ec{B}$ acting at an angle $ heta$:

Resultant Magnitude:   R = √(A² + B² + 2 A B cos θ)
Direction Angle α (with vector A⃗):
  tan α = (B sin θ) / (A + B cos θ)

Special Cases:
• Parallel (θ = 0°):       R_max = A + B
• Anti-parallel (θ = 180°): R_min = |A - B|
• Perpendicular (θ = 90°):   R = √(A² + B²),   tan α = B / A

✂️ Component Resolution in 2D & 3D

Resolving a vector into mutually perpendicular components along the coordinate axes simplifies complex multi-vector problems into independent 1D algebraic additions.

2D Resolution (Angle θ with x-axis):
  A_x = A cos θ,   A_y = A sin θ
  A = √(A_x² + A_y²),   tan θ = A_y / A_x

3D Direction Cosines (Angles α, β, γ with x, y, z axes):
  cos α = A_x / A,   cos β = A_y / A,   cos γ = A_z / A
  Fundamental Identity: cos² α + cos² β + cos² γ = 1

✖️ Scalar (Dot) & Vector (Cross) Products

Scalar (Dot) Product:   A⃗ · B⃗ = A B cos θ = A_x B_x + A_y B_y + A_z B_z
• Condition for Orthogonality: A⃗ ⊥ B⃗ ⇔ A⃗ · B⃗ = 0
• Work done: W = F⃗ · d⃗

Vector (Cross) Product: A⃗ × B⃗ = (A B sin θ) n̂
• Condition for Parallelism: A⃗ ∥ B⃗ ⇔ A⃗ × B⃗ = 0
• Torque: τ⃗ = r⃗ × F⃗
