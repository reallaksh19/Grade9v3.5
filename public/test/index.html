TEST: a sandbox for stress runs

TEST is a sandbox for stress runs. A test agent prepares Core2, then Core1A, then an explorer for the toughest concept of the same question set, and each lands here as a labelled draft. Nothing here is reviewed, accepted or curriculum, and accept_product.py refuses TEST.

A gap count of 0 means the depth check found nothing missing. It counts what is absent, not how good it is, and it does not say the content has been reviewed.
