Inertial ground frame

Physical forces only

Accelerating elevator frame

Same physical interactions + frame term

scale on person↑ N
Earth on person↓ mg
pseudo-force↓ m a_frame
Fpseudo = -m aframe
N - mg - m aframe = 0

Dual-frame cross-check

Ground frame inertial

Person accelerates with the elevator.

N - mg = m a

Elevator frame accelerating

Person is at rest relative to the cabin.

N - mg + Fpseudo = 0
Classifier: gravity and normal force are real interactions. The pseudo-force is a frame-dependent inertial term, not a Newton-III partner.

Transfer: hanging bob in a horizontally accelerating vehicle

Vehicle-frame equilibrium

tan(θ) = |aframe| / g
The bob tilts opposite the vehicle acceleration. If aframe → 0, θ → 0 and the string returns vertical.
