CANDIDATE A: BALL ON CURVED RAMP Constrained

A ball rolls without slipping along a smooth curved metal track under gravity.

✗ 1. ZERO CONTACT FORCES? FAILED (N ≠ 0)

The track exerts a continuous normal force N perpendicular to the curve.

✗ 2. HORIZONTAL ACCEL ZERO (aₓ = 0)? FAILED (aₓ ≠ 0)

Because the track is tilted, the normal force has a horizontal component: Nₓ = N sinθ ≠ 0.

✗ 3. PURE GRAVITATIONAL FALL (aᵢ = −g)? FAILED (aᵢ ≠ −g)

The vertical component of normal force partially offsets gravity: Nᵢ − mg ≠ −mg.

VERDICT: PROJECTILE MODEL REJECTED ✗ LOCKED

Applying x(t) = v₀ₓt and y(t) = v₀ᵢt − ½gt² here is completely invalid. The ball is not in free fall!

Governing Model: Constrained Curve Lagrangian / Work-Energy
Pedagogical Invariant: Kinematic equations are mathematically derived from Newton's Second Law (ΣF = ma). If the force interaction does not equal −mgĵ, the parabolic equations aₓ=0, aᵢ=−g do not apply — no matter how parabolic the curve looks!

A · CURVED RAMP REJECT

Visual Shape: Downward curved arc
Interactions: Gravity + Surface Normal N
Horizontal Accel: aₓ = Nₓ/m ≠ 0
Vertical Accel: aᵢ = (Nᵢ−mg)/m ≠ −g

Constrained motion. Do NOT use projectile equations!
B · POWERED DRONE REJECT

Visual Shape: Smooth arced climb/glide
Interactions: Gravity + Motor Thrust Fᵠ
Horizontal Accel: aₓ = Fᵠₓ/m ≠ 0
Vertical Accel: aᵢ ≠ −g

Continuous propulsion. Fᵠ drives ongoing acceleration.
C · FREE BALL (AIR) ✓ APPROVED

Visual Shape: Parabolic trajectory
Interactions: Gravity alone (mg)
Horizontal Accel: aₓ = 0 (no force)
Vertical Accel: aᵢ = −g (pure fall)

True ideal projectile. Unlocks aₓ=0, aᵢ=−g!
